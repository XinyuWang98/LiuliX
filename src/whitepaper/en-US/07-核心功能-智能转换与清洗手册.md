# 7. Core Function: Intelligent Conversion & Cleaning Manual

> **Last Updated**: 2026-01-13

LiuliX adopts an **"AI-First"** cleaning mode. You don't need to write Python code manually; the system automatically scans data and generates cleaning suggestions.

---

## AI-First Cleaning

### Workflow
1. **Auto Diagnosis**: After loading data, AI automatically analyzes data quality issues (e.g., nulls, outliers, format errors).
2. **Generate Suggestions**: The system recommends a set of cleaning operations (e.g., "Fill Missing Values", "Standardize Column Names").
3. **One-Click Apply**: User checks satisfied suggestions and clicks **Apply Selected** to execute.
4. **Code Execution**: The backend WASM engine executes the corresponding Python/SQL code.

---

## Cleaning Suggestion Types

The system automatically recommends cleaning operations based on column types. Here are some core skills:

### Text Cleaning
- **Trim Spaces**: Remove leading/trailing whitespace
- **To Lower/Upper**: Case conversion
- **Remove Punctuation**: Strip punctuation marks
- **RegEx Replace**: Regular expression replacement

### Numeric Processing
- **Fill Missing**: Smart filling (Mean/Median/Mode)
- **Outlier Handling**: Outlier detection and handling

### Structural Processing
- **Rename Columns**: Smart renaming
- **Drop Columns**: Remove redundant columns

---

## Operation History (History Log)

LiuliX records all executed cleaning operations, ensuring the data processing process is transparent and traceable.

### Feature Description
- **Audit Log**: View every executed operation record in the History panel.
- **Reset All**: If the analysis direction is wrong, supports one-click rollback to the initial data state.
