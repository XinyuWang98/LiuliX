# 3. Data Sanitization Policy

> **Last Updated**: 2026-01-13

This document details LiuliX's **Privacy Protection Mechanism** and **Data Sanitization Policy**. We implement strict privacy controls at the code level to enforce your data sovereignty.

---

## Core Principles

LiuliX follows the **"Minimize Data Exposure"** principle:

1. **Local-First**: We recommend using local models to ensure physical data isolation.
2. **User Control**: In cloud mode, users decide the granularity of data transmission.
3. **Transparent**: Clearly inform where every bit of data goes.

---

## Three Data Processing Modes

### 1. Local Mode
This is our **Strongly Recommended** mode.

- **Mechanism**: Run AI models via local Ollama.
- **Data Flow**: `Browser` <-> `Localhost (Ollama)`
- **Privacy Level**: **Full Privacy** (Data does not go to the cloud)
- **Scenario**: Financial data, medical data, corporate confidential data.
> [!NOTE]
> **Applicable Version**: This mode only supports **LiuliX Desktop**, which is currently under intensive development. The Web Online Version does not support connecting to local models.

---

### 2. Cloud Mode - Auto Sanitize
This is the **Default Safety Option** in cloud mode.

- **Mechanism**: The system automatically strips all specific values and extracts only metadata before sending the request.
- **Data Flow**: `Browser` → `Sanitizer` → `Cloud API`
- **Privacy Level**: **Metadata Level Privacy**
- **Uploaded Content**:
    - [Keep] **Column Names & Types** (e.g., `age: INTEGER`)
    - [Keep] **Basic Statistics** (e.g., `nullCount: 0`)
    - [Remove] **Specific Values** (Replaced with `"Sanitized"`)
    - [Remove] **Sample Data** (Completely removed)

> **Does AI Still Work?**
> Yes. AI can still generate effective data cleaning code based on column names and statistical features (such as missing rates, anomaly distributions), with an accuracy of about 90%.

---

### 3. Cloud Mode - Raw Data
This is an option for **Testing Only**.

- **Mechanism**: Sends a small amount of sampled data to obtain more accurate analysis.
- **Data Flow**: `Browser` → `Cloud API`
- **Privacy Level**: **General Privacy** (Risky)
- **Uploaded Content**:
    - [Keep] **Top 100 Rows of Sample Data** (Contains real values)
- **Risk Warning**: **Strictly Prohibited** to process Personally Identifiable Information (PII) in this mode.

---

## How to Configure Privacy Settings

1. Open **Settings**.
2. Go to **Performance & Quality**.
3. In the **Data Privacy** area, select:

- **( • ) Auto Sanitize [Recommended]**
  *Send only column names and statistics, no specific data values*

- **( ) Send Raw Data**
  *Send sampled data to Cloud API for more accurate suggestions*

> **Tip**: This option will be automatically disabled when you switch to "Use Local Model", as privacy sanitization is not needed in local mode.

## Technical Implementation Details

Our sanitization engine (`dataSanitizer.ts`) runs in the browser, ensuring data is processed before leaving your device.

**3.1 Smart PII Detection & Sanitization Rules**

Our sanitization engine (`src/utils/dataSanitizer.ts`) has built-in regex-based detectors. Upon a match, the following strategies are automatically applied:

| Sensitive Type | Keywords (Regex)       | Sanitization Strategy       | Real Data Example          | Sanitized Effect     |
| :------------- | :--------------------- | :-------------------------- | :------------------------- | :------------------- |
| **Name**       | `name`, `姓名`, `昵称` | Keep first char, mask rest  | `John Doe`                 | `J*******`           |
| **ID Card**    | `id_card`, `身份证`    | Keep first 6 last 4         | `110101199001011234`       | `110101********1234` |
| **Phone**      | `phone`, `mobile`      | Keep first 3 last 4         | `13812345678`              | `138****5678`        |
| **Email**      | `email`, `邮箱`        | Keep first 3 chars & domain | `support@liulix.com`       | `sup***@liulix.com`  |
| **Address**    | `address`, `地址`      | Keep city prefix only       | `Beijing Chaoyang Dist...` | `Beijing***`         |
| **Bank Card**  | `card`, `银行卡`       | Keep first 4 last 4         | `6222026000000001234`      | `6222********1234`   |
| **Password**   | `password`, `密码`     | Completely hide             | `MyP@ssw0rd`               | `******`             |

> **Tip**: Numerical types for non-sensitive columns will keep original values for statistical analysis, while text types will retain length information (e.g., "12 chars").

## FAQ

### Q: Is "Auto Sanitize" really safe?
**A**: Yes. In this mode, specific cell data (like "John Doe", "10000 USD") is **absolutely not** sent. AI only sees abstract statistical descriptions (like "This is an integer column with no missing values").

### Q: Why doesn't local mode need sanitization?
**A**: Because data never leaves your computer. LiuliX communicates directly with the Ollama service running on your machine, and the network request is a local loopback (`localhost`).

### Q: Do you store my data?
**A**: **Absolutely not**. LiuliX's backend service (`/api/proxy`) acts only as a transparent pipe forwarding requests to DeepSeek, and **does not log** or **store payloads**. The source code is open source, audit is welcome.
