## 🚀 Quick Start

### 👶 Getting Started
1. Read [**API Key Usage**](./02-使用须知-APIKey说明与限制.md) to understand the differences in AI modes.
2. Follow the [**Ollama Deployment Guide**](./01-新手教程-Ollama本地部署指南.md) to configure your local environment (Recommended).
3. If using Cloud Mode, please refer to the [**Data Sanitization Policy**](./03-隐私安全-数据脱敏策略说明.md).

### 🏢 Production Environment Checklist
- [ ] ✅ Install and run Ollama (Recommended Qwen2.5:7B)
- [ ] ✅ Enable "Use Local Model" in Settings
- [ ] ✅ (Alternative) If Cloud Mode is necessary, enable "Auto-Sanitize"
