# 9. 未来规划：LiuliX 演进路线图

> **最后更新**: 2026-01-13

我们持续迭代产品，旨在为用户提供更强大的本地数据探索体验。以下是近期的开发计划。

---

## Short-term (Q1 2026)

### 增强报表能力
- **Excel/PDF 导出**：支持将分析结果和图表导出为标准格式。
- **更多图表类型**：新增热力图 (Heatmap)、雷达图 (Radar) 和 桑基图 (Sankey)。

### BYO Key (Bring Your Own Key)
- 允许用户在前端配置自己的 OpenAI / Anthropic / DeepSeek API Key。
- 解除内置试用 Key 的额度限制。

---

## Mid-term (Q2 2026)

### 数据源扩展
- **SQLite / DuckDB 文件支持**：直接打开本地数据库文件。
- **PostgreSQL 连接器**：支持只读连接远程数据库进行分析。

### AI Agent 进化
- **多步推理 (Multi-step Reasoning)**：AI 能够自动拆解复杂任务，分步骤执行清洗和分析。
- **智能图表推荐**：根据数据分布自动生成最合适的图表。

---

## Long-term (2026+)

### 协作与分享
- **分析流分享**：将整个清洗分析步骤打包分享给同事。
- **本地知识库**：允许 RAG (检索增强生成) 索引本地文档，辅助数据分析。
