## 🚀 快速开始

### 👶 快速开始
1. 阅读 [**API Key 说明**](./02-使用须知-APIKey说明与限制.md) 了解 AI 模式的区别。
2. 按照 [**Ollama 部署指南**](./01-新手教程-Ollama本地部署指南.md) 配置本地环境（推荐）。
3. 如需使用云端模式，请参考 [**数据脱敏策略**](./03-隐私安全-数据脱敏策略说明.md)。

### 🏢 生产环境部署清单
- [ ] ✅ 安装并运行 Ollama (推荐 Qwen2.5:7B)
- [ ] ✅ 在 Settings 中启用 "Use Local Model"
- [ ] ✅ (备选) 如必须使用云端，请启用 "自动脱敏"
