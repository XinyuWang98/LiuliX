# 2. API Key 使用说明与限制

> **最后更新**: 2026-01-13

本文档旨在透明地说明 LiuliX 的 AI 服务策略及内置试用 Key 的使用限制。

---

## 核心策略

LiuliX Web 版采用 **"Cloud-Native"** (云原生体验) 策略，内置 DeepSeek 模型以提供开箱即用的分析能力。

### 三种使用模式

| 模式        | **Cloud Mode** (MVP内置) | **Desktop Mode** (桌面端)  | **BYO Key** (未来) |
| :---------- | :----------------------- | :------------------------- | :----------------- |
| **PRIVACY** | **数据上传** (即使脱敏)  | **完全离线** (Web版不支持) | **取决于供应商**   |
| **COST**    | **消耗额度**             | **免费**                   | **自费**           |
| **LIMIT**   | **严格限额**             | **无限制**                 | **供应商限额**     |
| **SCENE**   | **快速试用**             | **生产环境** (开发中)      | **特定需求**       |

---

## 试用额度说明

为了防止滥用并控制成本，内置的 DeepSeek API Key 设有严格的使用上限：

### 1. 邀请码用户 (MVP阶段)
- **总计**：**20 次** (清洗 + 洞察)
- **权限**：解锁云端 DeepSeek 模型使用权限。

### 2. 非邀请码用户
- **权限**：**受限**。
- **说明**：目前 Web MVP 版本需 **邀请码** 才能使用完整功能。我们正在开发桌面版以支持无限制的本地模型。

> **额度用尽后？**  
> 额度用尽后，建议加入我们的 **[Discord 社区](https://discord.gg/RnDvjtrs72)** 获取新邀请码，或申请 **LiuliX Desktop 离线版 (Beta)** 资格。

## 防滥用机制

我们实施了多层防护措施：

1. **后端限流**：基于 `x-invite-code` 追踪调用次数。
2. **熔断机制**：当额度耗尽时，API 将返回 `429 Too Many Requests`。
3. **前端引导**：UI 会明确提示 "试用配额" 字样，引导用户申请新额度。

**限制示例响应**：
```json
{
  "error": "邀请码额度已用完",
  "message": "您的邀请码额度已用完，请切换至本地模式继续使用。",
  "usage": 20,
  "limit": 20
}
```

## 常见问题 (FAQ)

### Q: 为什么 Web 版不能直接连本地模型？
**A**: 由于浏览器安全策略 (Mixed Content / CORS)，纯网页版无法直接访问您本地的 Ollama 服务。我们需要开发专属的 Desktop 客户端来打破这一限制。

### Q: 我可以购买更多额度吗？
**A**: 不可以。LiuliX 不销售 API 额度。如果您需要大量云端计算，建议等待 "Bring Your Own Key" (自定义 Key) 功能上线，直接使用您自己的 DeepSeek/OpenAI 账户。

### Q: 邀请码如何获取？
**A**: 请加入 Discord 社区领取。
