# MVP阶段产品策略

**创建时间**: 2025-12-21  
**适用阶段**: MVP 测试期 → 正式上线前

---

## 一、核心策略：免费 API Key 服务

### 1.1 决策背景

DataPrism 作为 AI 驱动的 EDA 工具，核心功能依赖于 DeepSeek API。为了降低用户使用门槛，在 MVP 阶段采取以下策略：

- **提供免费服务**：用户无需自行配置 API Key，系统默认使用我们提供的 DeepSeek API Key
- **简化首次体验**：移除 API 配置弹窗，用户打开即用
- **后期升级路径**：正式上线后引导用户配置自己的 Key（支持高级功能或去除限流）

### 1.2 实施方案

**前端修改** (`src/App.tsx`):
```typescript

// 等到正式部署上线后再启用此功能，引导用户配置自己的Key
// 首次加载检测 - 自动弹出API设置（已禁用）

//         setShowAPISettings(true);

```

**后端配置** (`server/index.js`):
- 清洗建议 API Key: 使用环境变量 `DEEPSEEK_API_KEY_CLEANING`（或回退到 `DEEPSEEK_API_KEY`）
- 洞察建议 API Key: 硬编码提供（`sk-33b37922d18d4783a4664b86022c5e5e`）

### 1.4 后续迁移计划

**正式上线阶段需要做的调整**：

1.  **前端**：取消注释 `App.tsx` 中的 `useEffect` 自动弹窗逻辑
2.  **引导文案**：在首次弹窗中说明：
    *   "DataPrism 提供限量免费额度，建议配置您自己的 API Key 以获得更好的体验"
    *   提供 DeepSeek 官网注册链接
3.  **配额管理**：
    *   监控系统 API Key 的使用量
    *   设置单用户每日调用上限（如 100次/天）
    *   超出额度后强制要求配置自己的 Key
4.  **后端**：移除硬编码的 Insight Key，强制使用环境变量

## 二、其他 MVP 策略

### 2.1 功能优先级

**P0 (必须完成)**:
- ✅ 数据清洗建议
- ✅ 洞察分析（AI + Pyodide）
- ✅ 基础数据可视化

**P1 (上线后优化)**:
- 多文件聚合分析
- IndexedDB 数据缓存
- DeepDive 对话模式

**P2 (长期规划)**:
- Prompt 库自定义
- 数据质量评分
- 导出分析报告

### 2.2 性能策略

- **清洗建议**: 30s 超时（快速响应）
- **洞察建议**: 120s 超时（深度分析）
- **数据采样**: 超过 10000 行自动采样到 1000 行

### 2.3 用户反馈收集

**MVP 阶段重点关注指标**:
- API 调用成功率
- 平均响应时间（清洗 vs 洞察）
- 用户留存率（7日）
- 功能使用频率排序

## 三、风险控制

### 3.1 API 成本风险

| 风险 | 缓解措施 |
|------|---------|
| 单日成本超标 | 设置日消耗上限（如 $50/day） |
| 恶意刷量 | IP 限流 + 单设备指纹识别 |
| Key 泄露 | 定期轮换 Key + 监控异常调用 |

### 3.2 法律合规

- ⚠️ **用户协议**: 在首页添加"免费额度使用条款"
- ⚠️ **隐私政策**: 明确数据不会被存储或用于训练
- ⚠️ **免责声明**: AI 生成结果仅供参考，不对准确性负责
