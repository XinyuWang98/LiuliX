## 1. 项目概览
- **核心目标**：纯前端本地运行，让数据分析师像带 AI 实习生一样，只负责审和盖章，不打断心流。
- **技术栈**：React + TypeScript + DuckDB-WASM + Chart.js + Prism.js + html2pdf.js + i18n
- **差异化优势**：零部署、隐私极致（数据永不上传）、证据链可追溯、老板敢直接看报告

#### **核心修复**
- **修复AI清洗Prompt Prompt为空问题 (#19)**：
    - 根因：`LeftSidebar` 与全局 `activeFile` 状态同步中断，导致 `columns` 信息丢失。

- **修复AI刷新逻辑竞态 (#24)** (P1):
    - 根因：`useInsightRefresh` 机械地阻止了所有 Pending 状态下的新请求，导致清洗后发起的刷新请求因“旧请求未结束”而被拦截，且旧请求返回后还清除了 Stale 标记。
    - 修复：采用抢占式策略——当数据变脏 (`isStale: true`) 时，`useInsightRefresh` 强制允许新请求发起；同时 `useInsightLoaderV2` 使用 `AbortController` 自动取消前一个未完成的请求。

- **修复Matplotlib中文乱码 (#25)** (P1):
    - 根因：Pyodide 默认环境只包含 DejaVu Sans 字体，缺失 CJK 字形。
    - 修复：
        - 后端：在 `worker.ts` 实现 `LOAD_FONT_URL` 指令，支持动态注入 `.ttf` 文件到 Matplotlib 字体库。
        - 架构：确立“按需加载 (On-Demand Loading)”策略，仅在中文环境下动态请求 `SimHei` 字体，避免打包体积膨胀。

#### **技术决策 (Technical Decisions)**
> [!IMPORTANT]
> **多语言字体支持策略**
> 为避免 100MB+ 的字体文件拖累应用性能，决定采用 **CDN + 按需动态加载** 方案：
> 1. **MVP阶段**：仅验证中文支持，字体内置或通过本地服务分发。
> 2. **V2阶段**：建立 `FontMap` 映射表（如 `ja: NotoSansJP`, `ko: NotoSansKR`），根据 `i18n` 设置动态 fetch 对应字体并在 Worker 侧缓存。
> 这在保持核心包轻量的同时，实现了无限的语言扩展能力。

### 2025-12-22（晚间21:50）✨ **战略调整：MVP核心确立**

#### **战略变更：用户可编辑 Prompt 库 > 全自动内测 Agent**
**决策背景**：基于市场分析与独立开发者资源现状，决定砍掉复杂的后台自动化内测 Agent，将资源集中在打造**“用户可编辑 Prompt 库” (User Editable Prompt Library)**。这不仅是降本增效，更是赋予用户掌控感的核心差异化卖点。

**MVP 核心交付物**：
1.  **Prompt 管理界面 (CRUD)**：允许用户新增、修改、删除 Prompt。
2.  **分享机制 (Share)**：支持一键复制 Prompt 配置为 JSON，以及通过 JSON 导入。
3.  **Prompt 结构定义 (Schema)**：

```typescript
interface UserPrompt {
  id: string;          // build-in-xxx 或 user-xxx
  title: string;       // 如 "电商-相关性分析"
  intent: string;      // 描述，用于意图匹配
  isBuiltIn: boolean;  // 是否官方预置（预置不可删，只可复制）
  
  // 核心逻辑配置
  template: {
    code: string;      // Python 代码模板，支持 {{col}} 占位符
    chartType?: 'bar' | 'line' | 'scatter'; // 期望图表类型
  };
  
  // 触发条件
  inputRequirements: {
    minColumns: number;
    colTypes: { name: string, type: 'number' | 'string' }[]; 
  };
}
```

**后续规划 (Roadmap)**：
- **v0.9.9 (本周)**：实现 CRUD 界面 + LocalStorage 存储 + 官方预置 10 个 Prompt。
- **v1.0 (下周)**：实现 JSON 导入/导出，建立社区分享基础。
