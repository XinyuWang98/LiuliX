# LiuliX 开发与设计核心规范

**版本**: v1.0
**生效日期**: 2025-12-30
**适用范围**: 全站前端开发

---

## 1. 🎨 视觉设计铁律 (Visual Strict Rules)

### 1.1 禁止硬编码 (No Hardcoding)
*   **严禁** 在 CSS/TSX 中直接使用 Hex 颜色值 (如 `#FFFFFF`, `#000000`)。
*   **严禁** 硬编码像素值用于核心布局 (如 `border-radius: 16px`)。
*   **必须** 使用 `src/styles/tokens/` 定义的 CSS 变量。

**❌ 错误示范**:
```css
.card {
    background: rgba(255, 255, 255, 0.1); /* 禁止 */
    border-radius: 12px; /* 禁止 */
    color: #fff; /* 禁止 */
}
```

**✅ 正确示范**:
```css
.card {
    background: var(--glass-surface);
    border-radius: var(--radius-l);
    color: var(--text-primary);
}
```

### 1.2 全局 Token 架构 (Token Architecture)
所有样式变量必须来源于以下文件，禁止局部定义 `:root` (除非特定覆盖)：
*   `_colors.css`: 语义化颜色 (`--bg-main`, `--text-accent`)
*   `_effects.css`: 玻璃态、阴影、光效 (`--glass-vignette-bg`, `--blur-ultra`)
*   `_layout.css`: 间距、圆角 (`--gap-m`, `--radius-xl`)
*   `_typography.css`: 字体系统

### 1.3 玻璃态标准 (Glassmorphism Standard)
LiuliX 使用 "Ascension" 主题，玻璃态分级如下：

| 等级 | 用途 | 变量组合 |
| :--- | :--- | :--- |
| **L1 (基础容器)** | 卡片、列表项 | `var(--glass-surface)` + `var(--blur-medium)` |
| **L2 (模态框)** | 弹窗、侧边栏 | `var(--glass-vignette-bg)` + `var(--blur-ultra)` |
| **L3 (高光装饰)** | 顶部/左侧边框 | `var(--glass-border-highlight)` (Fresnel Effect) |

## 2. 🧩 组件开发规范 (Component Rules)

### 2.1 优先复用原子组件
*   **Glass 容器**: 使用 `<LiuliGlass>` 或 `.glass-panel` 类。
*   **按钮**: 使用 `<LiuliButton>` 或 `.btn-primary` 等标准类。
*   **输入框**: 使用 `<LiuliInput>` 或 `.liuli-input` 类。

### 2.2 Z-Index 管理
*   **-1**: 背景层 (`AscensionBackground`)
*   **0**: 基础与修饰层
*   **1**: 主内容区 (Content)
*   **100**: 悬浮组件 (Dropdown, Tooltip)
*   **1000**: 模态框 (Modal Overlay)

---

## 3. 📂 目录与资源规范

### 3.1 CSS 位置
*   **全局 Token**: `src/styles/tokens/*.css`
*   **组件样式**: 必须与组件文件同级 (Co-location)，使用 CSS Modules 或 BEM 命名以防冲突。

### 3.2 资源引用
*   Agent 开发时如需查找变量，**必须** 优先查阅 `docs/01-架构设计/33-设计-CSS变量速查.md`。

---

## 4. 🚀 变更流程
若需新增颜色或修改核心视觉风格：
1.  修改 `src/styles/tokens/` 下的对应文件。
2.  更新 `33-设计-CSS变量速查.md`。
3.  在 `#/design` 演示页验证效果。
