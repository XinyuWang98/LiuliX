## 核心原则

> **"设计在前，开发在后，验收在尾"**  
> **"Token优先，禁止硬编码，复用为王"**

## 1. 🎨 视觉设计铁律（Visual Strict Rules）

### 1.1 禁止硬编码（No Hardcoding）
*   **严禁** 在 CSS/TSX 中直接使用 Hex 颜色值（如 `#FFFFFF`、`#000000`）
*   **严禁** 硬编码像素值用于核心布局（如 `border-radius: 16px`）
*   **严禁** 硬编码字体家族（如 `font-family: 'JetBrains Mono'`）
*   **必须** 使用 CSS 变量

**❌ 错误示范**:
```css
.card {
    background: rgba(255, 255, 255, 0.1); /* 禁止 */
    border-radius: 12px; /* 禁止 */
    color: #fff; /* 禁止 */
    font-family: 'Inter', sans-serif; /* 禁止 */
}
```

**✅ 正确示范**:
```css
.card {
    background: var(--glass-surface);
    border-radius: var(--radius-l);
    color: var(--text-primary);
    font-family: var(--font-family);
}
```

### 1.2 全局 Token 架构（Token Architecture）
所有样式变量必须来源于以下文件：
*   `_colors.css`: 语义化颜色（`--bg-main`、`--text-accent`）
*   `_effects.css`: 玻璃态、阴影、光效（`--glass-vignette-bg`、`--blur-ultra`）
*   `_layout.css`: 间距、圆角（`--gap-m`、`--radius-xl`）
*   `_typography.css`: 字体系统

### 1.3 玻璃态标准（Glassmorphism Standard）
LiuliX 使用 "Ascension" 主题，玻璃态分级如下：

| 等级              | 用途          | 变量组合                                         |
| :---------------- | :------------ | :----------------------------------------------- |
| **L1 (基础容器)** | 卡片、列表项  | `var(--glass-surface)` + `var(--blur-medium)`    |
| **L2 (模态框)**   | 弹窗、侧边栏  | `var(--glass-vignette-bg)` + `var(--blur-ultra)` |
| **L3 (高光装饰)** | 顶部/左侧边框 | `var(--glass-border-highlight)` (Fresnel Effect) |

### 1.4 排印与数据展示规范（Typography & Data）
*   **字体分工**：
    *   **UI/数据**: 必须使用 `var(--font-family)` (Sans)
    *   **代码/SQL**: 仅限代码编辑器使用 `var(--font-mono)`
*   **数值展示铁律**：所有统计数值、表格数据必须启用 `var(--font-sans)` + `font-feature-settings: 'tnum'` (等宽数字)，字重推荐 `500`，**禁止**使用 Mono 字体显示普通数值

## 2. 🧩 组件开发规范（Component Rules）

### 2.1 开发前检查（Pre-Development）

#### ① 检查 liulix 组件库
```bash
ls src/components/common/liulix/
```

**可用组件**：
- `LiuliGlass` - 玻璃容器
- `LiuliButton` - 按钮
- `LiuliInput` - 输入框
- `LiuliTag` - 标签
- `LiuliSwitch` - 开关

**规则**: 优先使用现有组件，禁止重复造轮子。

#### ② 对比 /design 页面
开发前访问 `http://localhost:5173/#/design` 查看：
- 目标视觉效果
- 玻璃态样式
- 颜色规范
- 字体规范

### 2.2 优先复用原子组件
*   **Glass 容器**: 使用 `<LiuliGlass>` 或 `.glass-panel` 类
*   **按钮**: 使用 `<LiuliButton>` 或 `.btn-primary` 等标准类
*   **输入框**: 使用 `<LiuliInput>` 或 `.liuli-input` 类
*   **统计展示**: **严禁**手写 Flex 布局，必须复用 `StatsPanel` 目录下的 `<NumericStatsPanel>` 或 `<CategoricalStatsPanel>`

### 2.3 代码示例

```tsx
// ✅ 推荐
<div className="liuli-glass">
  <button className="liuli-button">确认</button>
</div>

// ⚠️ 次选 - 仅当liulix组件不满足需求时
<div className="custom-container">  {/* 使用CSS变量 */}
  ...
</div>

// ❌ 禁止
<div style={{ background: 'rgba(...)' }}>  {/* 内联样式 */}
```

### 2.4 禁止事项
- ❌ 硬编码颜色值
- ❌ 硬编码像素值（魔法数字）
- ❌ 内联 `style` 写死样式
- ❌ 硬编码字符串（必须用 i18n）

### 2.5 Z-Index 管理
*   **-1**: 背景层（`AscensionBackground`）
*   **0**: 基础与修饰层
*   **1**: 主内容区（Content）
*   **100**: 悬浮组件（Dropdown、Tooltip）
*   **1000**: 模态框（Modal Overlay）

## 3. ✅ 提交前验收（Pre-Commit Checklist）

### 3.1 视觉验收
- [ ] 与 `/design` 页面对比，玻璃态效果一致
- [ ] 模糊度符合规范（medium 4px / heavy 8px）
- [ ] 高亮色使用蓝色 `rgba(10, 132, 255, 0.08/0.15)`

### 3.2 代码合规
- [ ] 无硬编码颜色（运行 `grep -r "rgba(" src/components/YourComponent`）
- [ ] 无硬编码像素值（所有尺寸使用变量或常量）
- [ ] 无内联样式（`style=` 仅用于动态计算值）
- [ ] 中文注释完整

### 3.3 国际化
- [ ] 所有用户可见文案使用 `t('key')`

### 3.4 文档更新
- [ ] 更新 `docs/02-开发日志/25-日志-V2样式迁移追踪.md` 状态为 ✅
- [ ] 更新 `docs/00-必读/01-核心-项目概览与现状.md` 最新变更章节

### 3.5 浏览器验证
- [ ] 刷新页面，F12 检查无报错
- [ ] Lighthouse Accessibility 检查通过

## 4. 📋 V2迁移完成度标准

一个模块被认为 "V2迁移完成" 需满足：

| 检查项     | 标准                            |
| ---------- | ------------------------------- |
| 玻璃态容器 | 100% 使用 `var(--glass-*)`      |
| 模糊效果   | 100% 使用 `var(--blur-*)`       |
| 颜色       | 100% 使用 CSS 变量              |
| 字体       | 100% 使用 CSS 变量              |
| 高亮色     | 蓝色（`rgba(10, 132, 255, *)`） |
| 视觉一致性 | 与 `/design` 页面无明显差异     |

## 6. 🔧 CSS 变量速查

### 玻璃态
| 变量              | 值                        | 用途       |
| ----------------- | ------------------------- | ---------- |
| `--glass-surface` | `rgba(255,255,255,0.005)` | 主容器背景 |
| `--glass-border`  | `rgba(255,255,255,0.15)`  | 边框       |
| `--blur-medium`   | `4px`                     | 标准模糊   |
| `--blur-heavy`    | `8px`                     | 重模糊     |

### 颜色
| 变量               | 值                 | 用途   |
| ------------------ | ------------------ | ------ |
| `--primary`        | `#0A84FF`          | 主色   |
| `--text-secondary` | `rgb(142,142,147)` | 次文本 |

### 字体
| 变量          | 值                    | 用途     |
| ------------- | --------------------- | -------- |
| `--fs-sm`     | `13px`                | 小字体   |
| `--font-mono` | `'SF Mono', Consolas` | 代码字体 |

**完整变量列表**: `docs/01-架构设计/33-设计-CSS变量速查.md`

## 7. ⚠️ 违规处理

- **发现硬编码**: 立即重构，记录到 `51-管理-错误日志记录.md`
- **视觉不一致**: 回退代码，重新对照 `/design` 开发
- **未更新迁移清单**: PR 被拒

---

## 8. 🚀 变更流程

若需新增颜色或修改核心视觉风格：
1. 修改 `src/styles/tokens/` 下的对应文件
2. 更新 `33-设计-CSS变量速查.md`
3. 在 `#/design` 演示页验证效果
