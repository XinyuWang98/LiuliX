# 双引擎记录方案 (Twin-Code Recording)

## 背景
当前 LiuliX 采用 **DuckDB (SQL)** 作为浏览器端交互式清洗的引擎，以追求极致性能；
而 **分析报告 (Report)** 模块采用 **Python (Pandas)** 作为通用数据分析语言。
这导致在生成分析报告时，数据清洗步骤（SQL）与后续分析步骤（Python）存在割裂感，无法形成完整的、可复现的纯 Python 数据分析工作流。

## 目标
消除技术栈割裂，实现“全 Python”的流畅分析叙事。
**核心策略**：保留 DuckDB 作为执行引擎，但在执行清洗操作时，**同时生成**对应的 Pandas 代码，并将其作为证据保存，用于报告展示。

## 架构设计

### 1. 规则类清洗 (Rule-Based)
针对固定的清洗模版（去重、填充、删除），建立 SQL 与 Pandas 的映射生成器。

*   **当前**: `sqlBuilder.ts` -> 生成 SQL
*   **新增**: `pandasBuilder.ts` -> 生成 Pandas 代码

**映射示例**:

| 操作类型            | DuckDB SQL (执行用)                                     | Pandas Python (报告用)                                  |
| :------------------ | :------------------------------------------------------ | :------------------------------------------------------ |
| **去重** (Dedup)    | `CREATE OR REPLACE TABLE t AS SELECT DISTINCT * FROM t` | `df = df.drop_duplicates()`                             |
| **填充缺失** (Fill) | `UPDATE t SET col = 0 WHERE col IS NULL`                | `df['col'] = df['col'].fillna(0)`                       |
| **删除列** (Drop)   | `ALTER TABLE t DROP COLUMN col`                         | `df = df.drop(columns=['col'])`                         |
| **类型转换**        | `ALTER TABLE t ALTER col TYPE DOUBLE`                   | `df['col'] = pd.to_numeric(df['col'], errors='coerce')` |

### 2. AI 类清洗 (AI-Suggest)
针对 AI 提出的复杂清洗建议，修改 Prompt 指令，要求 LLM 输出双语代码。

*   **Prompt 调整**:
    > "对于此数据质量问题，请提供 DuckDB SQL 用于立即修正，并提供等效的 Python Pandas 代码用于记录。"
    
*   **数据结构调整**:
    `CleaningSuggestion` 接口新增 `pythonCode` 字段。

### 3. 证据流转 (Data Flow)
打通从建议应用到报告生成的完整链路。

1.  **执行层 (`useCleaningExecution`)**:
    *   执行 SQL 成功后，将对应的 `pythonCode` (来自 Builder 或 AI) 存入证据池。
    *   调用 `addRecord` 时，传入 `python: string` 参数。

2.  **存储层 (`EvidenceRecord`)**:
    *   新增字段 `pythonCode?: string;`
    *   保留字段 `sql?: string;` (作为底层执行记录备份)

3.  **展示层 (`ReportContext`)**:
    *   报告生成逻辑中，对于 `cleaning` 类型证据：
        *   **优先使用** `pythonCode`。
        *   若无 `pythonCode`，才回退到 `sql` (作为降级方案)。
    *   语言标记设置为 `python`。

## 预期效果
用户在界面进行一连串清洗操作后，导出的 Notebook 将呈现无缝的 Python 代码流：

```python
# [Global Setup]
import pandas as pd
df = pd.read_csv('data.csv')

# [Data Cleaning] Deduplication
# 用户在界面点击"删除重复行"
df = df.drop_duplicates()

# [Data Cleaning] Fill Missing Values
# 用户在界面填充"age"列
df['age'] = df['age'].fillna(df['age'].mean())

# [Analysis] Correlation
# 用户进行相关性分析
sns.heatmap(df.corr())
```
