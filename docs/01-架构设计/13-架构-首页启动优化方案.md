# 13-体验优化-首页启动优化方案

## 1. 背景与现状

**现状**:
用户首次进入应用时，虽然已有默认项目 ("New Project 0")，但界面充满了"空状态"：
1.  **左侧数据源**: 空项目，仅有一个小的上传按钮。
2.  **中间工作区**: 显示了 "数据清洗"、"洞察分析"、"分析报告" 三个大模块，但内容全是灰色的 "暂无项目"、"暂无卡片"、"暂无报告"。
3.  **右侧工坊**: 虽然功能就绪，但用户不知道从何下手。

**问题**:
这种"冷启动"体验让用户感到迷茫（"我该做什么？"）和枯燥（"看起来没什么内容"）。缺乏明确的行动指引（Call to Action, CTA）。

## 2. 设计目标

1.  **缩短"Aha Moment"路径**: 让用户在 3 秒内知道该做什么（上传数据 或 使用演示数据）。
2.  **丰富空状态**: 将"暂无内容"的消极提示转变为"开始探索"的积极引导。
3.  **视觉层级引导**: 强化 "初次动作" 的视觉权重。

## 3. 优化方案详情

### 3.1 方案一：强化空状态引导 (MVP 优先)

针对现有各个区域的空状态进行视觉升级，添加直接的操作按钮。

#### A. 左侧侧边栏 (Left Sidebar)
*   **当前**: 仅顶部有小图标。
*   **优化**: 当项目列表为空，或选中项目无文件时，在侧边栏中部显示大号 **"拖拽上传"** 区域。
*   **文案**: "拖拽文件到这里，或点击上传"
*   **样式**: 虚线框，高亮色强调。

#### B. 中间工作区 (Center Area)
目前工作区默认展示三个空模块（清洗、洞察、报告），信息过载且无用。

*   **策略**: **智能折叠/渐进式展示**
    *   当项目无文件时，**隐藏** "洞察分析" 和 "分析报告" 模块，或将其折叠。
    *   **"数据清洗"模块 (或新增 "开始" 模块)**:
        *   显示巨大的 **"导入数据"** 卡片。
        *   提供 **"加载演示数据 (Titanic/Sales)"** 快捷按钮，一键体验全流程。

### 3.2 方案二：新建项目引导 (Onboarding)
在用户首次进入（无 `localStorage` 记录）时，显示轻量级引导遮罩。
*   Step 1: 指向左上角 "上传文件"。
*   Step 2: 简单介绍 "智能工坊"。

### 3.3 方案三：预置演示项目 (Demo Project)
用户首次进入时，不显示空白的 "New Project 0"，而是自动加载一个 **"示例项目：泰坦尼克号生存分析"**。
*   **状态**: 包含已上传的 `.csv` 文件。
*   **优势**: 用户直接看到数据表格、已生成的清洗建议，直接感受到产品价值。
*   **实现**: 在 `IndexedDB` 初始化时，如果没有项目，自动写入一个包含 Mock 数据的项目。

## 4. 实施计划 (Action Plan)

本次优先实施 **方案一 (强化空状态)** 和 **方案三 (加载演示数据入口)**。

### Phase 1: 视觉 CTA 升级
1.  **修改 `DataCleaner` 空状态**: 
    *   当检测到 `project.files.length === 0` 时，不显示 "暂无建议"，而是显示 **"开始您的数据之旅"** 面板。
    *   包含两个大按钮：`[上传本地文件]` `[试用演示数据]`。
2.  **修改 `ExplorationFlow`**:
    *   在无文件时，自动收起 "洞察" 和 "报告" 区块，避免干扰。

### Phase 2: 演示数据逻辑
1.  **新增 `DemoService`**:
    *   提供 `loadSampleProject()` 方法。
    *   内置一份轻量级 CSV (如 `Titanic.csv` 或 销售数据)。
    *   点击 "试用演示数据" 时，自动创建项目、加载文件、触发 DuckDB 使得表格有数据。

## 5. 预期效果
用户进入后，中心区域明确提示 "请上传文件或试用演示数据"。点击"演示数据"后，界面瞬间填充表格、清洗建议，用户能立即体验 AI 功能，完成 "Wowed" 的目标。
