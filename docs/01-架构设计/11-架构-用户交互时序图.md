## 🆕 架构升级亮点（v0.9.9）

### 1. **Pyodide本地化部署** ⚡
- 生产环境加载提升10-50倍（10-30秒 → 1-3秒）
- 支持完全离线使用
- CPU占用降低30%，风扇静音

### 2. **敏感数据检测** 🔒
- 三层检测：文件名 + 列名 + 内容
- 智能评分（0-100分）
- 自动提示本地模型保护隐私

### 3. **Generic Skills架构** 🛠️
- 从50+函数缩减到<10个通用Skills
- 统一权限管理（READ_ONLY/CLEANING/FULL）
- Token消耗降低80%

### 4. **API/本地模型双轨** 🎯
- API模式：DeepSeek云端（快速、准确）
- 本地模式：WebLLM浏览器端（安全、离线）
- 统一接口，对用户透明

### 5. **智能缓存优化** 🧠
- AI建议预加载（清洗、洞察）
- 分析结果持久化
- 智能失效机制
