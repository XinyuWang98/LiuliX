## 场景对比总结

### 关键差异点对比表

| 阶段 | 新上传文件 | 缓存文件 | 主要差异 |
|------|-----------|---------|---------|
| **文件加载** | 直接创建新表 | 可能需重建表 | ⚠️ 缓存tableName失效 |
| **规则建议** | 立即生成 ✅ | 可能失败(旧表) | ⚠️ 依赖tableName有效性 |
| **AI建议** | 使用当前tableName | 需动态更新tableName | ✅ 已修复(21:04更新) |
| **洞察刷新** | hypotheses=0触发 | isStale=true触发 | ✅ 智能刷新机制 |
| **Strict Mode** | 双重调用AI | 双重调用AI | 🔴 **主要问题** |

## 核心问题识别

### ✅ 问题1：React Strict Mode导致双重AI调用（已修复）

**位置**: `InsightChainFlow.tsx` useEffect

**现象**:
```javascript
// 开发模式日志
🔍 InsightChainFlow mounted/updated, hypotheses.length: 0
🔄 触发洞察刷新: {原因: '无缓存', ...}
🤖 调用AI生成假设...
✅ AI假设生成成功: 3 条

🔍 InsightChainFlow mounted/updated, hypotheses.length: 0  ← 第2次
🔄 触发洞察刷新: {原因: '无缓存', ...}  ← 第2次
🤖 调用AI生成假设...  ← 第2次 ❌
✅ AI假设生成成功: 3 条
```

**影响**:
- ✅ 仅开发环境
- ❌ 消耗2倍Token
- ❌ 增加响应时间

**解决方案**:
```typescript
// InsightChainFlow.tsx
const loadedOnceRef = useRef(false);

useEffect(() => {
    if (需要刷新 && 可以执行) {
        // 🟢 防Strict Mode重复
        if (loadedOnceRef.current) {
            console.log('[InsightChainFlow] ⏭️ Strict Mode重复调用已拦截');
            return;
        }
        loadedOnceRef.current = true;
        loadHypotheses();
    }
}, [hypotheses.length, insightCache?.isStale, insightCache?.status]);
```

**建议修复**:
```typescript
// useSuggestionGeneration.ts
let tableName = activeFile.data?.tableName;

// 验证并更新tableName
try {
    const engine = DuckDBEngine.getInstance();
    await engine.queryChunk(tableName, 0, 1); // 验证表存在
} catch (error) {
    // 表不存在,获取最新表
    const tables = await engine.queryChunk('information_schema.tables', 0, 100);
    const latestTable = tables
        .filter(t => t.table_name?.startsWith('t_'))
        .sort((a, b) => String(b.table_name).localeCompare(String(a.table_name)))[0];
    
    if (latestTable) {
        tableName = String(latestTable.table_name);
        console.log('[建议生成] 🔄 更新tableName:', activeFile.data?.tableName, '→', tableName);
    }
}
```
