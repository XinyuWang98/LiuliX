### 风险2：并发安全性 🟡 中风险

#### 问题描述

多个洞察并发执行时，`dataPreloader` 的缓存可能导致竞态条件。

#### 风险场景

**场景A：同表多次预加载**

```typescript
// 5个洞察并发开始，同时触发预加载
Promise.all([
    dataPreloader.preload('table_a'),  // 调用1
    dataPreloader.preload('table_a'),  // 调用2（重复）
    dataPreloader.preload('table_a'),  // 调用3（重复）
    // ...
]);
```

当前代码：
```typescript
async preload(tableName: string): Promise<PreloadedData> {
    if (this.cache.has(tableName)) {
        return this.cache.get(tableName)!;  // ✅ 缓存命中
    }
    
    // ❌ 问题：如果缓存未命中，多个调用会同时执行查询
    const data = await db.runQuery(...);  // 重复查询！
    this.cache.set(tableName, result);
}
```

#### 影响评估

- **严重程度**: 🟡 中等
- **影响**: 重复查询DuckDB，浪费资源但不影响正确性
- **概率**: 高（5个洞察并发启动）

#### 解决方案

**实现 Pending Promise 管理** ✅

```typescript
class DataPreloader {
    private cache = new Map<string, PreloadedData>();
    private pending = new Map<string, Promise<PreloadedData>>();  // ✅ 新增

    async preload(tableName: string): Promise<PreloadedData> {
        // 1. 检查缓存
        if (this.cache.has(tableName)) {
            return this.cache.get(tableName)!;
        }

        // 2. 检查是否正在加载 ✅ 关键
        if (this.pending.has(tableName)) {
            logger.log('Skills', '预加载进行中，等待完成', { tableName });
            return this.pending.get(tableName)!;
        }

        // 3. 创建加载Promise
        const loadPromise = this._doLoad(tableName)
            .finally(() => {
                this.pending.delete(tableName);  // 完成后清理
            });

        this.pending.set(tableName, loadPromise);
        return loadPromise;
    }

    private async _doLoad(tableName: string): Promise<PreloadedData> {
        // 实际加载逻辑
        const data = await db.runQuery(...);
        const result = { tableName, data, ... };
        this.cache.set(tableName, result);
        return result;
    }
}
```

### 风险3：内存泄漏 🟠 中高风险

#### 问题描述

`dataPreloader.cache` 无限增长，可能导致内存泄漏。

#### 风险场景

**场景：用户长时间使用，切换多个表**

```typescript
// 用户操作流程
1. 加载 table_a (100k行数据 → 缓存)
2. 加载 table_b (100k行数据 → 缓存)
3. 加载 table_c (100k行数据 → 缓存)
...
10. 加载 table_j (100k行数据 → 缓存)

// cache大小 = 10 * 100k * 14列 * 平均100字节 ≈ 1.4GB！
```

#### 影响评估

- **严重程度**: 🟠 中高
- **影响**: 内存占用过高，可能导致页面崩溃
- **概率**: 中（长时间使用）

#### 解决方案

**实现 LRU 缓存** ✅

```typescript
class DataPreloader {
    private cache = new Map<string, PreloadedData>();
    private pending = new Map<string, Promise<PreloadedData>>();
    private readonly MAX_CACHE_SIZE = 3;  // ✅ 限制缓存大小
    private accessOrder: string[] = [];   // ✅ LRU队列

    async preload(tableName: string): Promise<PreloadedData> {
        // ... 检查缓存、pending

        const result = await this._doLoad(tableName);
        
        // ✅ LRU淘汰逻辑
        this._updateCache(tableName, result);
        
        return result;
    }

    private _updateCache(tableName: string, data: PreloadedData) {
        // 添加到缓存
        this.cache.set(tableName, data);
        
        // 更新访问顺序
        this.accessOrder = this.accessOrder.filter(t => t !== tableName);
        this.accessOrder.push(tableName);
        
        // 淘汰最久未使用的
        while (this.cache.size > this.MAX_CACHE_SIZE) {
            const oldest = this.accessOrder.shift()!;
            this.cache.delete(oldest);
            logger.log('Skills', '缓存淘汰', { 
                data: { evicted: oldest, cacheSize: this.cache.size }
            });
        }
    }
}
```

### 风险4：数据一致性 🟡 中风险

#### 问题描述

表切换时，预加载的数据可能与实际执行的表不匹配。

#### 风险场景

```typescript

const preloadPromise = dataPreloader.preload('table_a');

// 2. 用户快速切换到 table_b

// 3. 预加载完成，但保存的是 table_a 的数据
context.preloadedData = await preloadPromise;  // table_a 数据

// 4. 执行时使用 table_b
executeFullMode(..., context);  // context.tableName = 'table_b'

// 5. 检测到不匹配
if (preloadedData.tableName !== tableName) {
    // ✅ 回退到即时查询
}
```

#### 影响评估

- **严重程度**: 🟡 中等
- **影响**: 性能下降（回退查询），但**不会数据错误**
- **检测**: ✅ 已有表名匹配检查

#### 缓解措施

**当前方案已足够** ✅

```typescript
// modeExecutor.ts
const preloadedData = context?.preloadedData;

if (preloadedData && preloadedData.tableName === tableName) {
    // ✅ 表名匹配，使用预加载数据
    data = preloadedData.data;
} else {
    // ✅ 不匹配，回退查询

        logger.warn('Skills', '表名不匹配，回退查询', {
            data: { 
                expected: tableName, 
                got: preloadedData.tableName

        });
```
