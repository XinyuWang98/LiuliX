## 📋 模块概述

**质量门控（Quality Gate）** 是洞察分析链路中的关键过滤器，负责在Skills执行前过滤低质量洞察。

**核心职责**：
- 🎯 **执行前过滤**：避免浪费计算资源在低质量代码上
- 📊 **4维度评分**：代码质量、AI置信度、数据覆盖、统计显著性
- ✅ **60分阈值**：总分≥60才通过
- 🚫 **拒绝原因**：记录详细的拒绝理由

### 1.1 完整验证时序图

```mermaid

    participant DataEval as 数据覆盖评估<br/>evaluateDataCoverage()
    participant SigEval as 显著性评估<br/>evaluateSignificance()
    participant Logger as logger
    
    Caller->>QG: validateInsight(insight)
    Note over QG: 初始化评分对象<br/>total=0, passed=false
    
    Note over QG: === 维度1：代码质量（0-30分）===
    QG->>CodeEval: evaluateCodeQuality(insight)

    alt 长度合理
        CodeEval->>CodeEval: +5分
    end
    
    CodeEval->>CodeEval: 检查必要导入<br/>import+matplotlib+base64
    alt 包含所需导入
        CodeEval->>CodeEval: +5分
    end
    
    CodeEval->>CodeEval: 检查数据处理逻辑<br/>包含'df'或'DataFrame'
    alt 包含数据处理
        CodeEval->>CodeEval: +10分
    end
    
    CodeEval->>CodeEval: 检查可视化代码<br/>包含'plt.'或'fig'
    alt 包含可视化
        CodeEval->>CodeEval: +10分
    end
    
    CodeEval-->>QG: 返回代码质量分数（0-30）
    QG->>QG: codeQuality = 返回值
    
    Note over QG: === 维度2：AI置信度（0-40分）===
    QG->>AIEval: evaluateAIConfidence(insight)
    
    AIEval->>AIEval: 检查标题长度<br/>3-50字符
    alt 标题合理
        AIEval->>AIEval: +10分
    end
    
    AIEval->>AIEval: 检查描述长度<br/>10-200字符
    alt 描述详细
        AIEval->>AIEval: +10分
    end
    
    AIEval->>AIEval: 检查双模式完整性<br/>full_mode + aggregated_mode
    alt 双模式都存在
        AIEval->>AIEval: +20分
    else 仅full_mode存在
        AIEval->>AIEval: +10分
    end
    
    AIEval-->>QG: 返回AI置信度分数（0-40）
    QG->>QG: aiConfidence = 返回值
    
    Note over QG: === 维度3：数据覆盖（0-20分）===
    QG->>DataEval: evaluateDataCoverage(insight)
    
    DataEval->>DataEval: 获取columns_used列表
    DataEval->>DataEval: 计算：列数 × 10<br/>最多20分
    
    alt 使用1个列
        DataEval->>DataEval: 10分
    else 使用2个列
        DataEval->>DataEval: 20分（封顶）
    else 使用3个以上列
        DataEval->>DataEval: 20分（封顶）
    end
    
    DataEval-->>QG: 返回数据覆盖分数（0-20）
    QG->>QG: dataCoverage = 返回值
    
    Note over QG: === 维度4：统计显著性（0-10分）===
    QG->>SigEval: evaluateSignificance(insight)
    
    Note over SigEval: ⚠️ 当前实现：<br/>默认给满分10分<br/>TODO: 未来基于统计检验
    SigEval->>SigEval: 返回固定值10分
    
    SigEval-->>QG: 返回显著性分数（10）
    QG->>QG: significance = 10
    
    Note over QG: === 计算总分与判定 ===
    QG->>QG: total = codeQuality + aiConfidence<br/>+ dataCoverage + significance
    QG->>QG: passed = (total >= 60)
    
    alt 总分 < 60分
        QG->>QG: 记录拒绝原因
        
        alt codeQuality < 15
            QG->>QG: reasons.push('代码质量不足')
        end
        
        alt aiConfidence < 20
            QG->>QG: reasons.push('AI置信度过低')
        end
        
        alt dataCoverage < 10
            QG->>QG: reasons.push('数据覆盖不足')
        end
    end
    
    Note over QG: === 日志记录 ===
    QG->>Logger: log('质量门控', '评分: X/100')
    Logger->>Logger: 记录详细breakdown<br/>{code, ai, coverage, sig}
    
    alt passed = false
        Logger->>Logger: 记录拒绝原因数组
    end
    
    QG-->>Caller: 返回QualityScore对象<br/>{total, passed, reasons, ...}
```

**实际代码示例**：
```typescript
// qualityGate.ts:102-131
function evaluateCodeQuality(insight: InsightForValidation): number {
    let score = 0;
    const code = insight.full_mode.code;

    // ✅ 检查1：代码长度（5分）
    if (code.length > 100 && code.length < 5000) {
        score += 5;
    }

    // ✅ 检查2：必要导入（5分）
    const hasImports = code.includes('import') &&
        code.includes('matplotlib') &&
        code.includes('base64');
    if (hasImports) {
        score += 5;
    }

    // ✅ 检查3：数据处理（10分）
    const hasDataProcessing = code.includes('df') || code.includes('DataFrame');
    if (hasDataProcessing) {
        score += 10;
    }

    // ✅ 检查4：可视化（10分）
    const hasVisualization = code.includes('plt.') || code.includes('fig');
    if (hasVisualization) {
        score += 10;
    }

    return score; // 最高30分
}
```

## 6. 已知限制与改进方向

### 6.1 当前限制 ⚠️

| 限制 | 影响 | 示例 |
|------|------|------|
| **无语法检查** | 语法错误的代码会通过 | `plt.plot(df['col1)` 缺引号仍得分 |

| **启发式弱** | 容易被骗 | `print('plt.')` 也会得分 |
| **显著性虚假** | 直接送10分 | 所有洞察都得满分 |
