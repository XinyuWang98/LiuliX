## 2. 优化设计理念

**“沉浸式智能流 (Immersive Intelligence Flow)”**

我们的目标是打造一个既专业又具未来感的分析工作台。设计应遵循以下原则：

1.  **光影指引 (Light as Guide)**：利用光晕、高亮和色彩强弱来引导用户的视觉焦点，而不是依靠大量的文字说明。
2.  **渐进式披露 (Progressive Disclosure)**：只在需要的时候展示内容。未激活的步骤应折叠或以紧凑模式展示，激活后展开。
3.  **微交互反馈 (Micro-feedback)**：用户的每一个操作（悬停、点击）都应有细腻的视觉反馈。

## 3. 具体优化方案 (Actionable Items)

### 3.1 🎨 视觉层级重构 (Visual Hierarchy)

*   **提升对比度**：
    *   将主背景色保持深色，但提升 Panel 背景色（`--bg-panel`）的亮度或调整透明度，增加层次感。
    *   关键文字（步骤标题）使用更亮的白色（`--text-primary`），辅助文字使用偏蓝灰的冷色调而非纯灰，提升高级感。
*   **强化时间轴**：
    *   左侧 Timeline 线条在“当前步骤”应发光（Glow Effect）。
    *   步骤序号（01/02/03）在激活状态下应放大并高亮。

### 3.2 🧩 布局与空间优化

*   **手风琴折叠模式 (Accordion Mode)**：
    *   对于 **02 洞察分析** 和 **03 分析报告**，在数据清洗未完成前，默认处于 **“紧凑状态”**（只显示标题栏和简短的锁定提示）。
    *   当清洗完成后，自动展开 **02 洞察分析**，并将页面以此为焦点滚动。
    *   **收益**：大幅减少无效的黑色空白区域，让首屏信息密度更加合理。

*   **空状态引导优化**：
    *   虽然移除了重复按钮，但可以在空状态区域增加一个 **“微光指引”** 动画，指向右上角的“生成AI建议”按钮，或者在空状态区域加一个**幽灵按钮 (Ghost Button)**（细边框、无背景），文案为“开始分析”，以此兼顾简洁与引导。

### 3.3 💅 细节打磨 (Polish)

*   **统一卡片容器**：
    *   确保 DataCleaner, InsightChain, ReportGenerator 使用统一的圆角（`--radius-l`）和边框样式。
    *   移除 ReportGenerator 内部多余的黑色背景，使其融入整体流。
*   **输入框悬浮感**：
    *   底部的 Chat 输入框可以设计为“悬浮胶囊”样式，增加阴影（`--shadow-lg`）和模糊背景（`backdrop-filter`），使其看起来是浮在内容之上的控制台。

## 4. 实施路线图 (Implementation Plan)

### 第一阶段：视觉修正 (T + 0.5 Day)
- [ ] 全局调整 CSS 变量，增强深色模式下的文字对比度。
- [ ] 优化 Timeline 组件样式，增加激活状态的光晕效果。
- [ ] 统一三大模块容器的边框和圆角变量。

### 第二阶段：布局重构 (T + 1 Day)
- [ ] 实现 Timeline 的“手风琴”折叠逻辑（未激活步骤高度压缩）。
- [ ] 优化 DataCleaner 空状态，增加指向性引导动画。

### 第三阶段：交互增强 (T + 1.5 Days)
- [ ] 为步骤切换添加平滑过渡动画（Framer Motion）。
- [ ] 升级底部输入框为悬浮样式。
