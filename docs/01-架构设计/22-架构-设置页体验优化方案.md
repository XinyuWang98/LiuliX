# 交互设计：设置页体验优化方案 (MVP修正版)

## 0. 设计评审与方案修正 (Sonnet Feedback Analysis)

基于 Sonnet 对原方案的深度评估，本修正版方案做出了以下关键调整，以确保方案的可落地性与纯粹性：

| 评审维度 | Sonnet 建议/风险提示 | 本方案修正策略 |
| :--- | :--- | :--- |
| **❌ 范围控制 (Scope)** | 原方案增加了未被要求的"系统提示词"功能，属于 **Scope Creep (需求蔓延)**。 | **移除**：删除所有未授权的新功能，严格聚焦于"体验优化"而非"功能新增"。 |
| **⚠️ 技术风险 (Tech)** | 此时盲目追求 WebGPU 模型的"完全无感热切换"风险极大，可能导致显存泄漏或崩溃。 | **降级 (Degradation)**：对 AI 模式切换采用"全屏遮罩 + 后台重载"的折中方案，不强求无感，但消除白屏闪烁。 |
| **🎨 视觉规范 (Visual)** | 原方案缺乏具体的 CSS 变量定义和设计细节。 | **补充**：在第 2 节新增 "2.2 样式规范"，明确定义了玻璃态参数与颜色变量。 |
| **🏗️ 架构重组 (IA)** | 建议不要为了改而改，原有的 4 分类结构若无大碍应保持，降低用户学习成本。 | **保留**：放弃原定对导航菜单的重构，沿用现有分类 (`常用`/`AI配置`/`性能`/`高级`)，仅优化单页内的布局。 |


## 1. 现状痛点与改进策略

| 痛点 | 严重级 | 改进策略 (MVP) |
| :--- | :--- | :--- |
| **全屏闪烁 (Hard Reload)** | P0 (高) | **分级处理**：<br>1. 主题/语言：必须实现 Context 热切换。<br>2. AI 模型：尝试服务级重载；若涉及 WebGPU 显存强占用，则改为"全屏 Loading 遮罩+自动初始化"，替代生硬的 F5 刷新。 |
| **信息过载 (Overload)** | P1 (中) | **折叠收纳**：<br>1. 硬件检测报告默认折叠，只显示核心评分。<br>2. 暂不使用的 API Key 自动折叠。 |
| **视觉粗糙 (Rough UI)** | P1 (中) | **设计对齐**：<br>引入 LiuliX 设计系统的 Glassmorphism 卡片和 Sidebar 布局。 |
| **功能混乱 (Group)** | P2 (低) | **保留架构，微调布局**：<br>保持现有 4 个一级分类不变，避免用户学习成本。 |

## 2. 视觉与布局设计 (Visual Specs)

### 2.1 整体架构 (Layout)

采用 **Sidebar + Detail** 悬浮模态框布局。

*   **容器 (Modal)**:
    *   Size: `900px` x `600px` (Fixed)
    *   Radius: `16px`
    *   Depth: `box-shadow: 0 25px 50px -12px rgba(0, 0, 0, 0.5)`
    *   Class: `.settings-modal-container`

*   **导航栏 (Sidebar)**:
    *   Width: `240px`
    *   Background: `var(--bg-sidebar)` (Semi-transparent)
    *   Content: 搜索框 + 4个一级导航项

*   **内容区 (Content)**:
    *   Padding: `32px`
    *   Background: `transparent`
    *   Scroll: 独立滚动区域

### 2.2 样式规范 (CSS Tokens)

```css
:root {
  /* 卡片容器：轻量级玻璃态，避免低端机性能问题 */
  --setting-card-bg: rgba(255, 255, 255, 0.03);
  --setting-card-border: 1px solid rgba(255, 255, 255, 0.08);
  --setting-card-radius: 12px;
  
  /* 交互反馈 */
  --active-item-bg: rgba(6, 182, 212, 0.15); /* Liuli Cyan */
  --active-item-text: #22d3ee;
  
  /* 动画曲线 */
  --ease-spring: cubic-bezier(0.175, 0.885, 0.32, 1.275);
}

/* 优化后的开关组件 */
.ios-switch {
  width: 44px;
  height: 24px;
  border-radius: 99px;
  transition: background 0.3s ease;
}
```

## 3. 详细交互设计

### 3.1 常用设置 (Commonly Used)

*   **主题切换**:
    *   **Action**: 点击主题卡片。
    *   **Feedback**: 选中卡片边缘出现 `scale(1.05)` 弹跳动效，全站颜色立即平滑过渡 (CSS transition: background-color 0.3s)。
*   **语言切换**:
    *   **Action**: Segmented Control (分段控制器)。
    *   **Feedback**: 文本即时更新，无需 Loading。

### 3.2 AI 配置 (AI Config) - *重点优化*

*   **本地模型开关**:
    *   **UI**: 放在顶部显眼位置的大型 Toggle Card。
    *   **Action**: 开启时，下方以 `AnimateHeight` 展开详细参数。
    *   **Feedback**: 
        *   开启瞬间：显示全屏半透明遮罩 "正在初始化 Neural Engine..."。
        *   不再触发 `window.reload()`。如果必须重置服务，只在后台重置 `LocalLLMService` 单例。
*   **硬件检测**:
    *   **默认**: 只显示 " ✅ 推荐：本地模式 (评分 92)" 精简条。
    *   **点击**: 展开显示详细 GPU/CPU 参数。
*   **API Keys**:
    *   **样式**: 列表项改为独立卡片。
    *   **测试**: 测试按钮集成在 Input 右侧，测试通过后 Input 边框变绿。

### 3.3 性能与高级 (Performance & Advanced)

*   **数字输入**: 滑动条 (Slider) + 数字输入框 组合，提供直观的阈值调整体验。

## 4. 实施路线 (Implementation Roadmap)

1.  **Phase 1: 结构重组 (React Only)**
    *   拆分 `SettingsPage.tsx` 为 Components (`Sidebar`, `Section`, `Switch`).
    *   实现 CSS 布局重构，不涉及逻辑变更。
2.  **Phase 2: 热切换逻辑 (Context/Service)**
    *   改造 `ThemeContext` 确保无缝切换。
    *   优化 `handleAIModeChange`，移除 reload，改为调用 `localLLMService.reload()` (需新增此方法)。
3.  **Phase 3: 微动效与细节**
    *   添加 Framer Motion 或 CSS Transitions。
    *   优化硬件检测的折叠动画。

## 5. 验收标准

1.  切换主题/语言时，页面**无任何闪烁**。
2.  打开设置页时，无明显卡顿 (FPS > 50)。
3.  所有设置项修改后，关闭设置页能正常保留状态。
