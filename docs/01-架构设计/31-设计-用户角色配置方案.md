## 📋 概述

本文档定义LiuliX平台的双角色用户配置方案。通过让用户选择"数据分析师"或"业务专家"角色，系统**仅对核心业务功能**应用针对性配置。

**核心理念**：
- 🎯 **数据分析师**：完全控制、可定制、技术导向
- ⚡ **业务专家**：自动化、易用性、结果导向

**配置范围**：
- ✅ **角色配置影响**：数据清洗、洞察分析、分析报告（核心功能）
- ❌ **保持独立**：AI配置、语言、主题、布局（用户自主选择）

---

## 👥 角色定义

### 🎯 数据分析师

- 熟悉SQL、Python等技术工具
- 关注数据细节和分析过程
- 需要完全控制和定制能力

### ⚡ 业务专家

- 关注业务洞察和决策支持
- 追求效率和快速产出
- 希望"开箱即用"的体验

## 💾 技术实现

### 配置数据结构（简化版）

```typescript
// src/types/userRole.ts

export type UserRole = 'analyst' | 'expert';

export interface UserRoleConfig {
  role: UserRole;
  
  // 数据清洗（核心）
  cleaning: {
    enableRouter: boolean;      // cleaning_router
    enableAI: boolean;          // cleaning_ai
    minSuggestions: number;     // min_suggestions
    showSQL?: boolean;          // [P1]
    enableSQLEdit?: boolean;    // [P1]
  };
  
  // 洞察分析（核心）
  insights: {
    maxColumns: number;         // analysis_max_columns
    timeout: number;            // analysis_timeout
    samplingRows: number;       // analysis_sampling_rows
    showCode?: boolean;         // [P1]
    enableCodeEdit?: boolean;   // [P2]
    chartStyle?: 'minimal' | 'business'; // [P2]
  };
  
  // 分析报告（核心，P2阶段）
  reports?: {
    template?: 'technical' | 'business';
    includeCodeAppendix?: boolean;
    exportFormats?: string[];
  };
}
```

### 预设配置

```typescript
// src/config/userRolePresets.ts

export const USER_ROLE_PRESETS = {
  analyst: {
    role: 'analyst',
    cleaning: {
      enableRouter: false,
      enableAI: true,
      minSuggestions: 5,
      showSQL: true,
      enableSQLEdit: true,
    },
    insights: {
      maxColumns: 50,
      timeout: 120,
      samplingRows: 100,
      showCode: true,
      enableCodeEdit: true,
      chartStyle: 'minimal',
    },
    reports: {
      template: 'technical',
      includeCodeAppendix: true,
      exportFormats: ['pdf', 'markdown', 'jupyter'],
    },
  },
  
  expert: {
    role: 'expert',
    cleaning: {
      enableRouter: true,
      enableAI: true,
      minSuggestions: 3,
      showSQL: false,
      enableSQLEdit: false,
    },
    insights: {
      maxColumns: 20,
      timeout: 60,
      samplingRows: 30,
      showCode: false,
      enableCodeEdit: false,
      chartStyle: 'business',
    },
    reports: {
      template: 'business',
      includeCodeAppendix: false,
      exportFormats: ['pdf', 'pptx'],
    },
  },
};

// 应用角色预设（仅核心功能）
export function applyRolePreset(role: UserRole): void {
  const config = USER_ROLE_PRESETS[role];
  
  // 数据清洗
  localStorage.setItem('cleaning_router', String(config.cleaning.enableRouter));
  localStorage.setItem('cleaning_ai', String(config.cleaning.enableAI));
  localStorage.setItem('min_suggestions', String(config.cleaning.minSuggestions));
  
  // 洞察分析
  localStorage.setItem('analysis_max_columns', String(config.insights.maxColumns));
  localStorage.setItem('analysis_timeout', String(config.insights.timeout));
  localStorage.setItem('analysis_sampling_rows', String(config.insights.samplingRows));
  
  // 保存角色标识
  localStorage.setItem('user_role', role);
  
  // 注意：不修改AI配置、语言、主题等
}
```

## ⚠️ 重要说明

### 配置独立性

**角色配置 ≠ 全局配置**

✅ **角色配置专注于**：数据清洗、洞察分析、分析报告  
❌ **不影响**：AI模式、语言、主题、布局

### 设计理念

- 角色配置优化**业务流程**
- 系统配置保持**用户自主权**
- 避免配置耦合，降低复杂度
