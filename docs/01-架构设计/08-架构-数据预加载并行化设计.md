# 数据预加载并行化架构设计 (V2 - Context方案)

> **版本**: V2 - 采用Context参数传递  
> **创建时间**: 2026-01-14  
> **关键改进**: 基于用户建议，采用 `context` 参数而非单独的 `preloadedData`

---

## 📊 方案对比

### ❌ 方案A：单独参数传递

```typescript
executeFullMode(
    suggestion,
    mode,
    tableName,
    promptId?,
    preloadedData?  // ❌ 参数列表会越来越长
)
```

**问题**：
- 每次新需求都要修改函数签名
- 参数列表过长，可读性差
- 与executor.ts的设计不一致

### ✅ 方案B：Context对象传递（推荐）

```typescript
executeFullMode(
    suggestion,
    mode,
    tableName,
    promptId?,
    context?  // ✅ 简洁且可扩展
)
```

**优点**：
1. **简洁** - 只需一个参数承载所有上下文
2. **可扩展** - 未来新字段直接加到ExecutionContext
3. **一致性** - 与executor.ts保持一致
4. **向后兼容** - context是可选参数

## 🎯 性能目标

**优化前**（78秒）:
```
AI响应 (21s) → 膨胀 (1.7s) → Worker初始化 (2.4s) 
  → 代码渲染 (2s) → [等待] 数据加载 (36s) → 执行 (15s)
```

**优化后**（42秒）:
```
AI响应 (21s) → 膨胀 (1.7s) 
  → { Worker初始化 (2.4s) + 数据预加载 (并行) }
  → 代码渲染 (2s) → 直接使用预加载数据 (0s) → 执行 (15s)
```

**性能提升**: **46%** (节省36秒)

### 步骤1：创建数据预加载服务

**文件**: `src/services/insights/dataPreloader.ts`

```typescript
import { logger } from '@/utils/logger';
import { DuckDBEngine } from '@/db/duckdbEngine';
import { calculateMaxRowsForPyodide } from '@/utils/memoryAssessment';

export interface PreloadedData {
    tableName: string;
    data: any[];
    totalRows: number;
    isLimited: boolean;
    columnCount: number;
    timestamp: number;
}

class DataPreloader {
    private cache = new Map<string, PreloadedData>();

    async preload(tableName: string): Promise<PreloadedData> {
        // 检查缓存
        if (this.cache.has(tableName)) {
            return this.cache.get(tableName)!;
        }

        const startTime = performance.now();
        const db = DuckDBEngine.getInstance();
        await db.init();

        // 获取schema
        const { getTableSchema } = await import('@/services/schemaService');
        const schema = await getTableSchema(tableName);
        const columnCount = schema.length;
        const maxRows = calculateMaxRowsForPyodide(columnCount);

        // 查询数据
        const countResult = await db.runQuery(
            `SELECT COUNT(*) as total FROM ${tableName}`
        );
        const totalRows = Number(countResult[0]?.total || 0);

        let query = `SELECT * FROM ${tableName}`;
        let isLimited = false;

        if (totalRows > maxRows) {
            isLimited = true;
            query = `SELECT * FROM ${tableName} LIMIT ${maxRows}`;
        }

        const data = await db.runQuery(query);
        const duration = performance.now() - startTime;

        logger.log('Skills', '数据预加载: ✅ 完成', {
            data: {
                tableName,
                实际加载行数: data.length,
                耗时: `${duration.toFixed(0)}ms`
            }
        });

        const result = {
            tableName,
            data,
            totalRows,
            isLimited,
            columnCount,
            timestamp: Date.now()
        };

        this.cache.set(tableName, result);
        return result;
    }

    clear(tableName?: string) {
        if (tableName) {
            this.cache.delete(tableName);
        } else {
            this.cache.clear();
        }
    }
}

export const dataPreloader = new DataPreloader();
```

### 步骤4：在 executor 中触发预加载

export async function executeBatchNodes(
    nodes: InsightNode[],
    context: ExecutionContext,
    _onProgress?: (current: number, total: number) => void,
    onNodeComplete?: (node: InsightNode) => void
): Promise<void> {
    // ... 策略评估、排序等逻辑

    // ========== 🚀 步骤：数据预加载（并行） ==========
    logger.log('AI服务', '[Executor] 🔄 开始数据预加载（并行）');

    const { dataPreloader } = await import('./dataPreloader');

    // 异步触发预加载（不等待）
    const preloadPromise = context.tableName 
        ? dataPreloader.preload(context.tableName)
        : Promise.resolve(null);

    // ... Worker初始化等步骤（并行进行）

    // 在执行前等待预加载完成
    try {
        const preloadedData = await preloadPromise;
        if (preloadedData) {
            // ✅ 保存到context
            context.preloadedData = preloadedData;
        }
    } catch (error) {
        logger.warn('Skills', '预加载失败，将在执行时回退', error);
    }

    // 执行节点（context会自动传递到executeAndFillResult）
    const wrappedCallback = async (node: InsightNode) => {
        const executorResult = await executeAndFillResult(
            node, 
            context  // ✅ 包含preloadedData
        );
        // ...
    };

    // 根据策略执行
    if (strategy.mode === 'parallel') {
        await executeParallel(sortedNodes, context, strategy.concurrency, wrappedCallback);
    } else {
        await executeSerial(sortedNodes, context, wrappedCallback);
    }
}

## 🔄 完整数据流

```
1. executor.ts: executeBatchNodes()
   ↓ 触发预加载
   dataPreloader.preload(tableName)
   ↓ 等待完成
   context.preloadedData = preloadedData

2. executor.ts: wrappedCallback()
   ↓ 传递context
   executeAndFillResult(node, context)

3. executor.ts: executeAndFillResult()
   ↓ 传递context
   executeInsightWithMode(..., context)

4. modeExecutor.ts: executeInsightWithMode()
   ↓ 传递context
   executeFullMode(..., context)

5. modeExecutor.ts: executeFullMode()
   ↓ 从context获取
   const preloadedData = context?.preloadedData
   ✅ 使用或回退
```

## 🛡️ 容错机制

### 1. 预加载失败回退

```typescript
try {
    const preloadedData = await preloadPromise;
    context.preloadedData = preloadedData;
} catch (error) {
    logger.warn('Skills', '预加载失败，将在执行时回退', error);
    // 继续执行，executeFullMode会自动回退到即时查询
}
```

### 2. 表名不匹配检测

```typescript
if (preloadedData && preloadedData.tableName === tableName) {
    // 使用预加载数据
} else {
    // 回退查询
}
```

### 3. Context为空处理

```typescript
const preloadedData = context?.preloadedData;  // 使用可选链
```

## 🎯 总结

### 为什么选择Context方案？

1. **更简洁** - 函数签名更清晰
2. **更灵活** - 未来扩展无需修改签名
3. **更一致** - 与现有代码风格统一
4. **更安全** - TypeScript类型检查

### 关键优势

- ✅ **性能提升46%** - 节省36秒
- ✅ **代码质量** - 更易维护和扩展
- ✅ **向后兼容** - context是可选参数
- ✅ **容错完善** - 预加载失败自动回退
