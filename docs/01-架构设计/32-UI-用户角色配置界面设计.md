# 用户角色配置UI展示方案

**基于现有设置页CSS变量设计**  
**版本**: v1.0  
**日期**: 2025-12-27

---

## 🎨 设计原则

基于现有SettingsPage.css的设计系统，保持视觉一致性：
- 使用已有的CSS变量（`--setting-card-bg`, `--setting-active-item-bg`等）
- 复用现有组件（`SettingsGroup`, `SettingsRow`, `Switch`等）
- 保持相同的交互模式（iOS风格开关、卡片式布局）

## 🎨 视觉设计

### 1. 角色选择卡片（大卡片，类似主题选择）

```tsx
// 使用现有 theme-card 样式扩展
<div className="role-selection-grid">  
  {/* 数据分析师 */}
  <div className={`role-card ${userRole === 'analyst' ? 'active' : ''}`}>
    <div className="role-icon">🎯</div>
    <div className="role-title">数据分析师</div>
    <div className="role-desc">
      熟悉SQL/Python<br/>
```
