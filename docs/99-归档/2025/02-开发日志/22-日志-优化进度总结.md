### ✅ 3. 数据采样工具 (C1)
**文件**: `src/utils/sampleData.ts`（新建）  
**功能**:
1. **自动采样**: 当表行数>1000时，自动采样前1000行
2. **格式化输出**: 支持CSV/JSON两种格式
3. **元数据记录**: 返回是否采样、采样行数、总行数

**核心函数**:
```typescript
// 采样数据用于AI调用
sampleDataForAI(tableName: string, limit = 1000): Promise<{
    sampledData: any[];
    metadata: { isSampled: boolean; sampleSize: number; totalSize: number; };
}>

// 格式化为AI可读格式
formatDataForAI(data: any[], format: 'csv' | 'json' = 'csv'): string
```

**优化效果**: 
- 大文件（如100万行）AI调用从传输全量数据改为仅传输1000行
- 预计性能提升: 数据传输量减少99.9%，API响应速度提升10-100倍
