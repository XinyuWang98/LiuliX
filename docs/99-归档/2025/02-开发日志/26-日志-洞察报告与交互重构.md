# 2026-01-05 开发日志：洞察报告与交互重构

## 1. 核心变更摘要

本日重点完成了**分析报告模块的深度重构**与**下钻交互体验的优化**，同时解决了DuckDB表名同步与Matplotlib中文乱码两个关键Bug。

### ✅ 分析报告模块重构 (Report Refactoring)
- **布局重组**：废弃了原有的 Tab 切换模式，采用**垂直流式布局**。
  - 顶部：**横向滚动证据池** (`EvidencePoolHorizontal`)，支持固定/取消固定。
  - 底部：**智能分析笔记本** (`ReportNotebook`)，无缝衔接。
- **视觉升级**：
  - 移除了冗余的 `report-section-title`。
  - 将 **Audit Progress Bar** (审计进度条) 完美集成到 Report Header 中。
  - 全面迁移至 **LiuliX Design System**，使用 CSS 变量 (`--glass-surface`, `--text-primary` 等) 替换硬编码样式。
  - 优化了模块间距 (统一 16px gap)。
- **组件拆分**：
  - 新增 `src/components/evidence/EvidencePoolHorizontal.tsx`
  - 新增 `src/components/evidence/EvidencePoolHorizontal.css`

### ✅ 洞察交互优化 (Insight Interaction)
- **下钻体验升级**：
  - 新增 `DrillDownRecommendationCard` 组件，将下钻建议从“药丸按钮”升级为**卡片式展示**，提供更丰富的信息（标题、描述、复杂度）。
  - 实现了 **双向同步** (Two-way Sync)：
    - 点击左侧卡片 → 右侧 Notebook 自动滚动定位 + 自动展开代码块 + 高亮。
    - 解决了**子卡片交互缺陷**：为 `InsightCardV2` 的 body 区域添加点击事件，现在点击卡片任意区域均可触发焦点同步。
  - **手风琴交互**：顶层 Insight 卡片实现互斥展开，保持界面整洁。

### ✅ 关键 Bug 修复
1.  **DuckDB 表名同步**：修复了重命名/清洗后 `tableName` 未同步导致的数据丢失问题，增加了 `DataLoadingService.cleanupInvalidTableName` 自动清理机制。
2.  **Matplotlib 中文乱码**：修复了 Pyodide 环境下 Matplotlib 无法显示中文的问题，实现了后台异步加载 `SimHei` 字体。
3.  **i18n 修正**：统一将 "Insight Chain" / "洞察链" 更名为 "**Insight Analysis**" / "**洞察分析**"。
