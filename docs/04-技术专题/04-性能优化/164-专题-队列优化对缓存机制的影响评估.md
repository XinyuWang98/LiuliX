### 2. 现有缓存失效机制

#### 清洗建议缓存
```typescript
// useSuggestionGeneration.ts L255-257
if (activeFile?.analysisCache?.cleaning?.suggestions?.length > 0
```

**触发条件**：
- `isStale === true`（清洗应用后标记）
- `suggestions`为空

**触发条件**：

- `lastModified`变化

## 🔍 队列优化的影响评估

### ✅ 完全兼容的部分

#### 1. `isStale`标记机制
**现有机制**：
```
用户采纳清洗 → lastModified更新 → insight.isStale = true
```

**队列优化后**：
```
用户采纳清洗 → lastModified更新 → insight.isStale = true
                                  ↓
                              中断正在进行的洞察请求
                                  ↓
                              重新生成Prompt（高优先级）
```

**结论**：✅ 兼容，队列优化是对现有机制的增强，不冲突。

---

#### 2. 缓存复用逻辑
**现有机制**：
```typescript
// 清洗建议：检查缓存有效性
if (cachedSuggestions && !isStale) {
    return cachedSuggestions;
}
```

**队列优化后**：
```typescript
// 保持不变，队列优化不影响缓存复用逻辑
if (cachedSuggestions && !isStale) {
    return cachedSuggestions;
}
```

**结论**：✅ 兼容，队列只管理请求顺序，不修改缓存判断。

**影响评估**：

- **收益**：⚡ 减少3秒Prompt构建时间

#### 2. 中断后的缓存状态

**场景**：洞察请求被中断

**现有行为**：
```
AbortController.abort() → 请求取消 → 无缓存更新
```

**队列优化后需确保**：
```
AbortController.abort() → 请求取消 → insight.isStale保持true
                                  ↓
                              重新排队 → 生成新的洞察
```

**潜在问题**：
- 如果中断时已部分生成结果，需要清理

**解决方案**：
```typescript
// 中断时强制标记为Stale
if (aborted) {
    file.analysisCache.insight.isStale = true;
    file.analysisCache.insight.status = 'pending';
}
```

**影响评估**：
- **兼容性**：✅ 现有`isStale`机制已支持
- **需改动**：⚠️ 需在abort()时额外标记状态

---

#### 3. 批量调度与缓存预加载

**队列优化**：File1完成后自动触发File2

**现有机制**：
```
用户切换文件 → useEffect触发 → 检查缓存 → 生成或复用
```

**队列优化后**：
```
File1完成 → 队列自动触发File2清洗
         → File2检查缓存（首次应该为空）
         → 生成并缓存
```

**潜在冲突**：
- 如果File2已有缓存（上次会话），需要判断是否使用

**建议策略**：
```typescript
// 批量调度时检查缓存新鲜度
const cacheAge = Date.now() - file.analysisCache.cleaning.timestamp;
const MAX_CACHE_AGE = 24 * 60 * 60 * 1000; // 24小时

if (cacheAge > MAX_CACHE_AGE) {
    file.analysisCache.cleaning.isStale = true;
}
```

**影响评估**：
- **兼容性**：⚠️ 需添加`timestamp`字段到缓存结构
- **收益**：✅ 避免使用过期缓存

### 建议2：统一缓存失效策略

```typescript
// 新建 src/utils/cacheManager.ts
export class CacheManager {
    static invalidateInsightCache(file: ProjectFile) {
        if (file.analysisCache?.insight) {
            file.analysisCache.insight.isStale = true;
            file.analysisCache.insight.status = 'pending';
        }
        // 同时清空Prompt缓存
        if (file.analysisCache?.promptCache) {
            file.analysisCache.promptCache.insight = undefined;
        }
    }
    
    static isCacheFresh(cache: any, maxAge: number = 24 * 60 * 60 * 1000): boolean {
        if (!cache?.timestamp) return false;
        return Date.now() - cache.timestamp < maxAge;
    }
}
```
