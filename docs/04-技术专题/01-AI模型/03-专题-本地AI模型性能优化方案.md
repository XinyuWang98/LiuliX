## 📝 技术细节

### 为什么保留median（数值列）？

**数据分析最佳实践**:
- 存在异常值时，中位数填充优于均值填充
- 例如工资数据：[3K, 5K, 8K, **500K**] → median=6.5K, mean=129K

**SQL实现复杂度**:
```sql
-- 如果不提供median，AI需要生成复杂SQL
WITH median_val AS (
  SELECT PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY salary) AS med 
  FROM table WHERE salary IS NOT NULL
)
UPDATE table SET salary = COALESCE(salary, (SELECT med FROM median_val));

-- 如果提供median=6500，AI可以直接用
UPDATE table SET salary = COALESCE(salary, 6500);
```

**结论**: 提供median值，AI可生成更简洁正确的SQL

### 为什么移除avgLength（文本列）？

**冗余原因**: 样本值已隐含长度信息

```typescript
// 当前Prompt（冗余）
"avgLength": 11,
"sampleValues": ["13812345678", "13998765432", "13700001111"]

// AI从样本值即可推断：
// 1. 长度约11位
// 2. 格式是手机号
// 3. 都是数字
```
