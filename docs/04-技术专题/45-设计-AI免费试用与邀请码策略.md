## 🎁 免费试用策略

### 额度配置

| 用户类型 | 清洗建议次数 | 洞察建议次数 | 总计 | 计数方式 |
|---------|------------|------------|------|---------|
| 免费用户 | 5次 | 5次 | 10次 | 分开计数 |
| 邀请码用户 | - | - | 20次 | 共用计数 |

### 用户类型判断

```
用户首次访问
    ↓
检查是否有邀请码
    ├─ 有 → 邀请码用户 (20次共用额度)
    └─ 无 → 免费用户 (5次清洗 + 5次洞察)
```

### 超限提示

**免费用户超限**:
```

请输入邀请码或配置 API Key 以继续使用

[输入邀请码] [前往设置]
```

**邀请码用户超限**:
```
❌ 邀请码额度已用完 (20次)
请配置您的 API Key 以继续使用

[前往设置]
```

## 🔑 邀请码策略

### 邀请码特权

- ✅ 20次AI使用额度（清洗+洞察共用）
- ✅ 优先体验新功能
- ✅ 专属标识（导航栏金色✨图标）

### 邀请码格式

- 大小写不敏感
- 自动转大写存储
- 示例: `LIULIX2025`, `DATAPRISMMVP`, `BETA001`

### 验证流程

```
用户输入邀请码
    ↓
前端验证格式
    ↓
后端验证白名单 (/api/validate-invite-code)
    ├─ 有效 → 保存到localStorage → 升级为邀请码用户
    └─ 无效 → 提示错误
```

## 🏗️ 技术实现

### 用户标识

**双重存储机制**:
```typescript
// localStorage (主存储)
localStorage.setItem('liulix_user_id', 'user_xxx_abc');

// Cookie (备份恢复)
document.cookie = 'liulix_uid=user_xxx_abc; expires=...';
```

**防绕过等级**:
- 🟢 普通用户：99%有效
- 🟡 技术用户：可绕过（清除存储）
- 🔴 恶意用户：无法防御（MVP阶段可接受）

**特性**:
