# ⚠️ API Key 使用说明与限制

本文档说明 LiuliX 的 AI 服务策略和内置 API Key 的使用限制。

---

## 🎯 AI 服务策略（MVP 阶段）

LiuliX 提供三种 AI 使用模式：

### 1️⃣ **本地模式（推荐）**
- 使用 Ollama 本地模型
- **隐私**：数据完全离线，不上传云端
- **成本**：完全免费
- **限制**：无限制
- **适用场景**：所有生产环境

### 2️⃣ **云端模式（内置 Key，试用）**
- 使用平台内置的 DeepSeek API Key
- **隐私**：数据上传云端 _（注：可通过设置启用数据脱敏，详见 [数据脱敏策略说明](./🔒数据脱敏策略说明.md)）_
- **成本**：消耗邀请码额度
- **限制**：**20 次 AI 调用/邀请码**（清洗 + 洞察总计）
- **适用场景**：仅供快速体验和测试

### 3️⃣ **自定义 API Key（未来）**
- 配置你自己的 DeepSeek / OpenAI / Claude API Key
- **隐私**：取决于你的 API 提供商
- **成本**：你自己承担
- **限制**：取决于你的 API 配额
- **适用场景**：生产环境，需要云端 AI 时

---

## 🔑 内置 API Key 限额策略

### **免费用户**（无邀请码）
- **清洗建议**：5 次
- **洞察分析**：5 次
- **总计**：10 次

### **邀请码用户**
- **总调用次数**：20 次（清洗 + 洞察合计）
- **超限后**：提示配置 API Key 或使用 Ollama

### **超限提示示例**
```json
{
  "error": "邀请码额度已用完",
  "message": "您的邀请码额度已用完，请配置 API Key 继续使用",
  "usage": 20,
  "limit": 20,
  "userType": "invite"
}
```

---

## ⚠️ 重要警告

### **内置 Key 仅供试用**
- ❌ **禁止用于生产环境**
- ❌ **禁止批量调用或自动化脚本**
- ❌ **禁止分享邀请码给他人滥用**

### **推荐做法**
1. **本地开发/测试**：使用 Ollama 本地模型
2. **生产环境**：
   - 优先使用 Ollama（数据隐私最佳）
   - 或配置你自己的 API Key（如 DeepSeek Pro）

---

## 🛡️ 防滥用机制

### **后端限流**
- 基于 `x-invite-code` header 追踪使用量
- 超限返回 HTTP 429 状态码
- 内存存储，服务重启后重置（测试阶段）

### **前端提示**
- 云端模式下显示"试用配额"提醒
- 推荐用户切换到本地模式

## 💬 常见问题

### Q: 为什么要限制内置 API Key？
A: 云端 AI 服务按调用次数收费，为防止滥用和控制成本，我们设置了合理限额。推荐使用免费的 Ollama 本地模型。

### Q: 额度用完了怎么办？
A: 
1. **最佳方案**：安装 Ollama，切换到本地模式（零成本）
2. **临时方案**：配置你自己的 DeepSeek API Key（未来支持）

### Q: 为什么不开放无限额度？
A: 云端 API 有实际成本，无限制会导致平台无法维持。我们鼓励用户使用本地模式，既保护隐私又零成本。
