# 专题分析：欢迎页营销文案与价值主张升级

**日期**: 2026-01-07
**对应版本**: v1.1.0 (Marketing Update)

## 1. 背景与目标 (Context)

需将欢迎页的价值主张 (Value Proposition) 从 **"功能特性导向"** 升级为 **"用户场景导向"**。
通过三个具体的 Storytelling 场景，直击用户痛点（环境配置繁琐、数据隐私担忧、黑盒交付困难），建立更强的产品共鸣。

---

## 2. 价值点重构分析 (Value Prop Restructuring)

### 场景一：零配置与全栈集成 (Zero Config & Full Stack)
*   **用户痛点**: 新人入职安装环境（Python/Conda/Pip）耗时耗力；出差断网无法工作。
*   **核心价值**: **"Deep Integration" (深度集成)**。
*   **旧文案**: "零配置极速启动" (侧重启动速度)
*   **新文案建议**: 
    *   **标题**: **开箱即用的数据工坊** (Works Right Out of the Box)
    *   **描述**: 深度集成 Python 与 DuckDB 引擎。新人入职无需配置繁琐环境，点开即用。即使在万米高空断网环境，也能流畅处理千万级数据。
*   **视觉建议**: 
    *   图标从 `Zap` (快) 替换为 **`PackageOpen`** (开箱) 或 **`GlobeLock`** (离线/全球可用)。

### 场景二：本地优先与隐私 (Local First & Privacy)
*   **用户痛点**: 只有 API 模式，数据必须上传，担心合规问题。
*   **核心价值**: **"Choice & Control" (选择与控制)**。
*   **旧文案**: "本地执行 / 离线可用" (侧重能力)
*   **新文案建议**: 
    *   **标题**: **数据隐形衣** (Your Data, Your Rules)
    *   **描述**: 默认本地模型运行，数据永远不出本机。既有本地的绝对隐私，又预留了 API 的强大能力。丰俭由人，合规尽在掌握。
*   **视觉建议**: 
    *   图标从 `Lock` (锁) 保持为 **`ShieldCheck`** (安全盾) 或 **`Cpu`** (本地算力)。

### 场景三：白盒审计与透明交付 (Auditability & Delivery)
*   **用户痛点**: AI 瞎写代码不敢信；分析结果是黑盒；汇报时老板没装软件打不开。
*   **核心价值**: **"Trust & Deliverable" (信任与交付)**。
*   **旧文案**: "分析即报告" (侧重结果)
*   **新文案建议**: 
    *   **标题**: **听话的超级实习生** (Transparent & Auditable)
    *   **描述**: 拒绝黑盒，清洗与分析过程自动生成**可读代码**。一键导出独立交互式 HTML 报告，老板无需安装软件，直接在浏览器中检阅你的完美工作。
*   **视觉建议**: 
    *   图标从 `FileOutput` (导出) 替换为 **`FileCode`** (代码/白盒) 或 **`Send`** (交付)。
