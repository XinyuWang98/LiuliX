# 外部模型集成指南 (DeepSeek MCP)

本文档指导如何在 Antigravity 中集成 DeepSeek 模型作为辅助 Agent。

## 1. 简介
通过 MCP (Model Context Protocol) 协议，我们可以将外部模型能力封装为工具，供 Antigravity 的主 Agent 调用。
本次集成使用的是 `deepseek-mcp-server`，它将 DeepSeek 的 API 转换为 MCP 协议。

## 2. 前置准备
- **Node.js 环境**: 确保本地已安装 Node.js (建议 v18+)。
- **DeepSeek API Key**: 访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 获取。

## 3. 配置步骤

### 3.1 安装与构建
由于 `npx` 直接运行 GitHub 仓库可能不稳定，我们采用了**本地源码构建**的方式。
代码已克隆至 `/Users/catherinewang/.gemini/antigravity/deepseek-mcp-server` 并完成编译。

### 3.2 修改配置文件
编辑 `/Users/catherinewang/.gemini/antigravity/mcp_config.json` 文件：

```json
{
  "mcpServers": {
    "deepseek": {
      "command": "node",
      "args": [
        "/Users/catherinewang/.gemini/antigravity/deepseek-mcp-server/build/index.js"
      ],
      "env": {
        "DEEPSEEK_API_KEY": "sk-YOUR_API_KEY_HERE"
      },
      "disabled": false
    }
  }
}
```

> [!IMPORTANT]
> 请务必将 `sk-YOUR_API_KEY_HERE` 替换为你实际的 API Key。

### 3.2 验证安装
配置完成后，重启 Antigravity (或重新加载窗口)。
Antigravity 会自动尝试连接该 MCP Server。

## 4. 使用方式
连接成功后，Antigravity 将具备以下新能力（具体取决于 Server 实现）：
- 聊天/问答: `ask_deepseek` 或类似工具。
- 代码生成: 利用 DeepSeek v3/R1 的能力辅助编程。

## 5. 常见问题
- **Q: 连接失败？**
  - 检查 `mcp_config.json` 语法是否正确。
  - 检查 `DEEPSEEK_API_KEY` 是否有效。
  - 尝试手动在终端运行 `npx -y github:DMontgomery40/deepseek-mcp-server`看是否有报错。
