## 二、技术实现方案

### 🔐 **认证方式**（符合 LiuliX 隐私原则）

**推荐方案**: **用户自配 API Token（前端直连）**

```typescript
// 前端直接调用 Kaggle API，数据不经过后端
interface KaggleConfig {
  username: string;
  apiKey: string;  // 存储在 localStorage（加密）
}
```

**优势**:
- ✅ 符合"数据永不上传"原则
- ✅ 用户自负责配额（Kaggle 免费额度充足）
- ✅ 无后端成本
- ✅ 满足 Kaggle ToS（Terms of Service）

### 🏗️ **架构设计**

```
用户界面
    ↓
KaggleDataSource 组件
    ↓
Kaggle API Client（前端）
    ↓ HTTPS 直连
Kaggle API Servers
    ↓ 下载 CSV
浏览器 IndexedDB（本地存储）
```

### 📦 **核心功能模块**

#### 1. Kaggle API 客户端

```typescript
// src/services/kaggleService.ts
class KaggleService {
  // 搜索数据集
  async searchDatasets(query: string): Promise<Dataset[]>
  
  // 下载数据集
  async downloadDataset(ref: string): Promise<File>
  
  // 列出热门数据集
  async listPopularDatasets(): Promise<Dataset[]>
}
```

#### 2. UI 组件

**数据源选择器扩展**:
```
┌─────────────────────────────────────┐
│ 数据源                               │
├─────────────────────────────────────┤
│ 📁 本地文件                          │
│ 🌐 Google Sheets                    │
│ 🏆 Kaggle 数据集（新增）             │
└─────────────────────────────────────┘
```

**Kaggle 导入流程**:
```
Step 1: 配置 API Token (首次使用)
    ↓
Step 2: 搜索/浏览数据集
    ↓
Step 3: 预览元数据（行数/列数/大小）
    ↓
Step 4: 一键导入到 DuckDB
```

## 三、实施路线（MVP）

### Phase 1: 基础集成（2-3 天）

- [ ] **API 客户端**: 封装 Kaggle REST API（搜索、下载）
- [ ] **认证管理**: API Token 配置页面（Settings）
- [ ] **热门数据集**: 预置 10 个经典数据集快速访问

### Phase 2: UI 优化（1-2 天）

- [ ] **搜索界面**: 支持关键词搜索、标签筛选
- [ ] **预览功能**: 显示数据集描述、列信息
- [ ] **进度提示**: 大文件下载进度条

### Phase 3: 高级功能（可选，V2）

- [ ] **竞赛集成**: 直接访问 Kaggle 竞赛数据
- [ ] **元数据缓存**: 避免重复 API 调用
- [ ] **协作功能**: 团队共享 Kaggle 数据集配置

## 四、安全与合规

### 🔒 **数据安全**

| 风险           | 缓解措施                   |
| -------------- | -------------------------- |
| API Token 泄露 | 前端加密存储 + HTTPS Only  |
| 数据隐私       | 数据仍存 IndexedDB，不上传 |
| CORS 限制      | Kaggle API 支持跨域请求    |

### 📜 **Kaggle ToS 合规**

- ✅ **允许**: 个人用户通过 API 访问公开数据集
- ✅ **允许**: 教育/研究用途
- ⚠️ **禁止**: 商业用途需额外授权（LiuliX MVP 为非商业）
