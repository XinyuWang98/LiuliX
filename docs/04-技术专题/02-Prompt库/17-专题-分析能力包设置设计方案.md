# 17-专题-分析能力包设置设计方案

> **文档性质**: 技术方案设计
> **生成时间**: 2025-12-26
> **关联模块**: Settings, Pyodide Worker, Prompt Library

---

## 1. 背景与目标

高级分析功能（回归、决策树、聚类等）依赖额外的 Python 库（sklearn、statsmodels），这些库体积较大，会显著增加首次加载时间。

**目标**: 让用户自主选择需要的分析能力，做到 **"按需加载，知情选择"**。

---

## 2. 能力包清单

| 能力包 ID | 库名 | 大小 | 分析方法 | 可视化图表 |
| :--- | :--- | :--- | :--- | :--- |
| `basic` | pandas, numpy, matplotlib | ~8MB | 分布、相关、趋势、GroupBy | 直方图、散点图、折线图、箱线图 |
| `sklearn` | scikit-learn | ~12MB | K-Means聚类、决策树/随机森林 | PCA 降维散点图、决策树图、特征重要性条形图 |
| `statsmodels` | statsmodels | ~8MB | OLS 回归、Holt-Winters 时序预测 | 系数森林图、预测折线图、置信区间 |
| `scipy-extra` | scipy (扩展) | ~5MB | 假设检验 (T/ANOVA/Chi²) | P 值表格、置信区间图 |

---

## 3. 数据结构定义

```typescript
// src/types/analysisPackage.ts

export interface AnalysisPackage {
  id: string;                    // 如 'sklearn'
  name: string;                  // 显示名称: 'Scikit-Learn 机器学习'
  pyodidePackages: string[];     // Pyodide 包名: ['scikit-learn']
  sizeEstimate: string;          // 预估大小: '~12MB'
  methods: AnalysisMethod[];     // 包含的分析方法
  isBuiltIn: boolean;            // 是否内置 (basic 为 true)
}

export interface AnalysisMethod {
  promptId: string;              // 对应的 Prompt ID: 'worker-cluster-v1'
  name: string;                  // 方法名: 'K-Means 聚类'
  description: string;           // 简述: '发现数据中的潜在群体'
  outputCharts: string[];        // 图表类型: ['PCA 散点图', '雷达图']
}
```

## 4. UI 设计

### 4.1 设置页布局

```
┌─────────────────────────────────────────────────────────────┐
│ ⚙️ 分析能力设置                                              │
│ 勾选需要的分析能力，系统将在启动时下载对应的 Python 库          │
├─────────────────────────────────────────────────────────────┤
│ ☑️ 基础分析 (内置，始终加载)                   📦 ~8MB        │
│    ├─ 分布分析      → 直方图、柱状图                         │
│    ├─ 相关性分析    → 散点图、热力图                         │
│    └─ 趋势分析      → 折线图、移动平均                       │
├─────────────────────────────────────────────────────────────┤
│ ☐ 机器学习 (scikit-learn)                     📦 ~12MB       │
│    ├─ K-Means 聚类  → PCA 降维散点图                         │
│    ├─ 决策树        → 决策树可视化图                         │
│    └─ 随机森林      → 特征重要性条形图                       │
├─────────────────────────────────────────────────────────────┤
│ ☐ 统计建模 (statsmodels)                      📦 ~8MB        │
│    ├─ OLS 回归      → 系数森林图 (Coefficient Plot)          │
│    └─ 时序预测      → 预测线 + 置信区间                      │
└─────────────────────────────────────────────────────────────┤
                                    [ 保存并应用 ]              │
                                    (需重新启动分析引擎)         │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 交互细节
- **展开/折叠**: 每个能力包可展开查看详细方法和图表预览。
- **依赖提示**: 如果某个 Prompt 需要未加载的包，在使用时提示 "请在设置中启用 XX 能力包"。
- **加载状态**: 显示各包的下载/加载进度。

---

## 5. 实现路径

### Phase 1: 数据层 (MVP)
1. 创建 `src/types/analysisPackage.ts` 定义数据结构。
2. 创建 `src/config/analysisPackages.ts` 维护能力包清单。
3. 扩展 `useSettings` Hook 存储用户选择。

### Phase 2: Worker 层
1. 修改 `pyodide/worker.ts`，根据用户设置动态加载包。
2. 添加 `LOAD_PACKAGES` 消息类型支持运行时按需加载。

### Phase 3: UI 层
1. 在 Settings 页面添加 "分析能力" 配置面板。
2. 实现能力包列表的展开/折叠和复选框。

---

## 6. 总结

这个设计将 DataPrism 从"一刀切加载"升级为"按需定制"，既尊重了用户的选择权，也为未来扩展更多分析能力（如深度学习、图分析）预留了扩展点。
