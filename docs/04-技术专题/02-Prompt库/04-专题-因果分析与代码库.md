# 专题 - 因果分析方法与常用代码库

## 1. 概述

因果分析（Causal Inference）的核心目标是从数据中推断“改变 X 是否会导致 Y 发生变化，以及变化的程度”。

在 DataPrism 项目中，为了保证 AI 产出的可信度，我们将分析方法按**“证据效力优先级”**进行分级整理。

---

## 2. 核心假设与前置条件（必读）

**🔴 警告：因果分析不是魔法。必须首先确认数据满足以下基本假设。**

1.  **无未观测的混淆变量（Unconfoundedness）**：除了下文提到的 RDD/DID/IV 外，大部分方法假设所有共同原因都已记录。
2.  **正值假设（Positivity）**：每个特征组合的样本都有概率接受干预。
3.  **SUTVA 假设**：样本间无相互干扰。

---

## 3. 此刻该用哪个？—— 方法选择决策树（优先级指南）

AI Agent 应按照以下**优先级顺序**检查数据特征，选择最可信的方法：

1.  **【最高优先级】是否存在明确的“干预阈值”？**
    *   ✅ 是（如分数>60及格，信用分>600放贷） → **RDD (断点回归)**
    *   *证据由断点处的局部随机性提供，最接近 RCT 实验。*

2.  **【次高优先级】是否有“干预前后的多期面板数据”？**
    *   ✅ 是（有对照组） → **DID (双重差分)**
    *   ✅ 是（无明确对照组，只有单一干预对象） → **SCM (合成控制法)**
    *   *利用时间趋势差分消除不随时间变化的混淆。*

3.  **【第三优先级】是否存在“工具变量”？**
    *   ✅ 是（找到一个只影响 X 不影响 Y 的变量 Z） → **IV (工具变量法)**
    *   *解决 X 与残差相关（内生性）的问题。*

4.  **【通用兜底】以上都没有，只有普通的观测数据？**
    *   ✅ 需构建复杂因果图 → **DoWhy (通用框架)**
    *   ✅ 需平衡组间差异 → **PSM (倾向得分匹配)**
    *   *强依赖“无未观测混淆”假设。*

5.  **【特定目标】**
    *   ❓ 谁对干预最敏感？ → **Uplift Modeling**
    *   ❓ 时间序列A能否预测B？ → **Granger Causality**
    *   ❓ 完全不知道结构？ → **Causal Discovery**

## 4. 第一优先级：准实验设计 (Quasi-Experiments)
*数据包含特殊的“自然实验”结构，结论可信度最高。*

### 4.1 断点回归 (RDD - Regression Discontinuity Design)
**场景**：干预由连续变量的 Cutoff 决定。

```python
import statsmodels.formula.api as smf
import pandas as pd

def run_rdd_analysis(df: pd.DataFrame, running_variable: str, outcome: str, cutoff: float, bandwidth: float = None):
    """
    Sharp RDD 分析
    """
    df['centered_running'] = df[running_variable] - cutoff
    df['treatment'] = (df['centered_running'] > 0).astype(int)
    
    if bandwidth:
        data_subset = df[abs(df['centered_running']) <= bandwidth]
    else:
        data_subset = df
        
    # 模型: Y ~ T + X + T*X (允许左右斜率不同)
    formula = f"{outcome} ~ treatment * centered_running"
    model = smf.ols(formula=formula, data=data_subset).fit()
    
    return {
        "coef_treatment": model.params['treatment'],
        "p_value": model.pvalues['treatment'],
        "summary": model.summary().as_text()
    }
```

### 4.2 双重差分 (DID - Difference-in-Differences)
**场景**：面板数据，需满足**平行趋势假设**。

```python
import statsmodels.formula.api as smf
import pandas as pd

def run_did_analysis(df: pd.DataFrame, time_col: str, group_col: str, outcome_col: str, intervention_time: int, treatment_group_id):
    """
    标准 2x2 DID 分析
    """
    df['post'] = (df[time_col] >= intervention_time).astype(int)
    df['treatment_group'] = (df[group_col] == treatment_group_id).astype(int)
    
    # 交互项 post:treatment_group 即为 ATT
    formula = f"{outcome_col} ~ post * treatment_group"
    model = smf.ols(formula=formula, data=df).fit()
    
    return {
        "did_estimate": model.params.get('post:treatment_group', None),
        "p_value": model.pvalues.get('post:treatment_group', None),
        "summary": model.summary().as_text()
    }
```

## 5. 第二优先级：工具变量 (Instrumental Variables)
*如果存在工具变量，可解决未观测混淆问题，证据效力优于普通观测推断。*

### 5.1 工具变量法 (IV)
**场景**：存在未观测混淆 + 存在有效工具变量 Z（与干预相关，与残差无关）。

```python
from linearmodels.iv import IV2SLS
import pandas as pd

# Y ~ Exog + [Endog ~ Instruments]
def run_iv_analysis(df: pd.DataFrame, dependent: str, exog: list[str], endog: list[str], instruments: list[str]):
    model = IV2SLS(
        dependent=df[dependent],
        exog=df[exog] if exog else None,
        endog=df[endog],
        instruments=df[instruments]
    ).fit()
    return {"params": model.params.to_dict(), "summary": str(model.summary)}
```

## 6. 第三优先级（通用兜底）：观测数据推断 (Observational Inference)
*最常用的通用方法，但严重依赖“混淆变量已观测”假设。当前面的准实验条件不满足时使用。*

### 6.1 DoWhy 通用框架 (推荐首选)
**优势**：强制画 DAG，流程标准化（Model-Identify-Estimate-Refute）。

```python
import dowhy
from dowhy import CausalModel
import pandas as pd

def run_dowhy_analysis(df: pd.DataFrame, treatment: str, outcome: str, common_causes: list[str], method: str = "backdoor.linear_regression"):
    """
    DoWhy 全流程分析
    """
    try:
        # 1. Model
        model = CausalModel(
            data=df, treatment=treatment, outcome=outcome,
            common_causes=common_causes, logging_level="ERROR"
        )
        
        # 2. Identify
        identified_estimand = model.identify_effect(proceed_when_unidentifiable=True)
        
        # 3. Estimate
        estimate = model.estimate_effect(identified_estimand, method_name=method)
        
        # 4. Refute (验证是 DoWhy 的核心优势)
        refute_random = model.refute_estimate(identified_estimand, estimate, method_name="random_common_cause")
        refute_placebo = model.refute_estimate(identified_estimand, estimate, method_name="placebo_treatment_refuter")

        return {
            "status": "success",
            "estimate": estimate.value,
            "refute_random": refute_random.new_effect,
            "refute_placebo": refute_placebo.new_effect, # 应接近0
            "robustness": "High" if abs(refute_placebo.new_effect) < abs(estimate.value)*0.2 else "Low"
        }
    except Exception as e:
        return {"status": "error", "message": str(e)}
```

### 6.2 倾向得分匹配 (PSM)
**场景**：需要平衡组间特征差异，模拟随机实验。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import NearestNeighbors
import pandas as pd
import numpy as np

def run_psm_analysis(df: pd.DataFrame, treatment: str, outcome: str, covariates: list[str]):
    # 1. 计算 Propensity Score
    ps_model = LogisticRegression().fit(df[covariates], df[treatment])
    df['ps'] = ps_model.predict_proba(df[covariates])[:, 1]
    
    # 2. 区分组别
    treated = df[df[treatment] == 1]
    control = df[df[treatment] == 0]
    
    # 3. KNN 匹配
    nn = NearestNeighbors(n_neighbors=1).fit(control[['ps']])
    dists, indices = nn.kneighbors(treated[['ps']])
    matched_control = df.iloc[control.index[indices.flatten()]]
    
    # 4. 平衡性检验 (SMD)
    balance = {}
    for col in covariates:
        t_mean, c_mean = treated[col].mean(), matched_control[col].mean()
        pool_std = np.sqrt((treated[col].var() + matched_control[col].var()) / 2)
        balance[col] = abs(t_mean - c_mean) / pool_std
        
    # 5. ATT 估算
    att = treated[outcome].mean() - matched_control[outcome].mean()
    
    return {"att": att, "balance_smd": balance} # SMD < 0.1 为佳
```

## 7. 其他特定场景工具 (Specialized Tools)

### 7.1 Uplift Modeling
**场景**：营销领域，寻找“对干预最敏感的人群”（CATE）。

```python
from causalml.inference.meta import LRSRegressor
def run_uplift(df, treatment, outcome, features):
    learner = LRSRegressor()
    cate = learner.fit_predict(X=df[features], treatment=df[treatment], y=df[outcome])
    return cate
```

### 7.2 格兰杰因果 (Granger Causality)
**场景**：时间序列预测关系检验（非物理因果）。

```python
from statsmodels.tsa.stattools import grangercausalitytests
def run_granger(df, x, y, max_lag=3):
    # input format: [y, x]
    res = grangercausalitytests(df[[y, x]], maxlag=max_lag, verbose=False)
    return {lag: val[0]['ssr_ftest'] for lag, val in res.items()}
```

## 7. 总结

1.  **AI 自动化逻辑**：应先检测是否符合 RDD/DID 的严格条件，符合则优先使用（Results High Confidence）。
2.  **人机回环**：若使用 DoWhy/PSM，必须向用户展示 DAG 或平衡性检查结果，确认“无遗漏关键变量”。
3.  **验证第一**：所有输出必须附带不同程度的验证指标（P值、Placebo Test、SMD等）。
