## 一、日志分组优化方案

### 1.1 现状问题

**控制台日志混乱**：
```
[AI服务] xxx
[数据清洗] xxx
[AI服务] xxx  
[洞察分析] xxx
```
- 清洗和洞察的日志交织在一起
- 难以快速定位问题
- 重复日志过多（如 `[洞察分析] 🔍 完整data结构` 出现20+次）

### 1.2 优化方案

#### 方案A：使用 console.group 分组（推荐）

**实施位置**：
- `src/services/aiCleaningService.ts` - 清洗建议生成
- `src/components/insights/InsightChainFlow.tsx` - 洞察建议生成

**示例代码**：
```typescript
// 清洗建议
logger.group('AI清洗', '生成清洗建议流程');
logger.log('AI清洗', '数据脱敏中');
logger.log('AI清洗', '调用API');
logger.log('AI清洗', 'SQL校验通过: 3条');
logger.groupEnd();

// 洞察建议
logger.group('AI洞察', '生成洞察建议流程');
logger.log('AI洞察', '获取列信息: 99条');
logger.log('AI洞察', '调用API');
logger.log('AI洞察', 'Pyodide执行: 3条');
logger.groupEnd();
```

**效果**：
```
▼ [AI清洗] 生成清洗建议流程
  [AI清洗] 数据脱敏中
  [AI清洗] 调用API
  [AI清洗] SQL校验通过: 3条
▼ [AI洞察] 生成洞察建议流程
  [AI洞察] 获取列信息: 99条
  [AI洞察] 调用API
  [AI洞察] Pyodide执行: 3条
```

#### 方案B：独立服务名 + 颜色标识

**配置** (`src/utils/logger.ts`):
```typescript
const SERVICE_COLORS = {
  'AI清洗': '#10b981', // 绿色
  'AI洞察': '#3b82f6', // 蓝色
  'DuckDB': '#8b5cf6',
  'Python': '#f59e0b'
};
```

**效果**：
- 清洗日志统一显示为绿色
- 洞察日志统一显示为蓝色
- 浏览器Console可以按服务名过滤

#### 方案C：减少冗余日志

**优化点**：
1. **去重检测重复日志**：
   - `[洞察分析] 🔍 完整data结构` 只输出一次
   - 后续相同内容直接跳过
   
2. **合并进度日志**：
   ```typescript
   // 旧：每个进度点都输出
   logger.log('Python', '执行进度更新: 1条 1/3');
   logger.log('Python', '执行进度更新: 2条 2/3');
   logger.log('Python', '执行进度更新: 3条 3/3');
   
   // 新：只输出关键节点
   logger.log('Python', '批量执行开始: 3条');
   logger.log('Python', '批量执行完成: 3条成功 0条失败');
   ```

3. **条件日志**：
   ```typescript
   // 开发模式：详细日志
   // 生产模式：只输出错误和关键信息
   if (import.meta.env.DEV) {
     logger.log('AI洞察', '详细调试信息');
   }
   ```

## 二、AI 洞察响应速度优化方案

### 2.1 现状分析

**问题**：
```
[AI服务-洞察] ⚠️ 调用失败: Request timed out
```

**耗时分析**（99列数据集）：
| 阶段 | 耗时 | 占比 |
|------|------|------|
| 1. DESCRIBE获取列信息 | ~100ms | 1% |
| 2. 数据采样 (1000行) | ~200ms | 2% |
| 3. 构建Prompt | ~50ms | <1% |
| **4. AI API调用** | **60-120s+** | **95%+** |
| 5. Pyodide执行 | 2-5s | 3% |

**瓶颈确认**：AI API调用时间过长，导致超时。

### 2.2 优化方案

#### 方案1：Prompt大小优化 ⭐⭐⭐⭐⭐

**问题根源**：99列 + 1000行采样数据 → Prompt巨大 → DeepSeek处理慢

**优化策略**：

**1.1 智能列筛选**
```typescript
// 按列重要性排序，只发送Top 20列
const topColumns = selectTopColumns(columns, {
  priorityRules: [
    'numeric > categorical',      // 数值型优先
    'low_missing > high_missing', // 缺失少的优先
    'high_variance > low_variance' // 方差大的优先
  ],
  maxColumns: 20
});
```

**1.2 采样数据压缩**
```typescript
// 当前：发送1000行 × 99列 = 99000个值
// 优化：发送100行 × 20列 = 2000个值 (减少98%)
const compactSample = sampleDataForAI(tableName, 100);
```

**预期效果**：
- Prompt大小：从 50KB → 5KB（减少90%）
- AI响应时间：从 120s → 20-30s（减少75%）

#### 方案2：分批生成 + 流式返回 ⭐⭐⭐⭐

**当前问题**：用户等待120s才能看到任何结果

**优化方案**：
```typescript
// 分3批生成，每批1-2条洞察
async function* generateInsightsStreaming() {

  yield await askAIInsight(anomalyPrompt);
}
```

**用户体验**：
- 10s 后看到第1条洞察 ✅
- 25s 后看到第2条洞察 ✅
- 45s 后看到第3条洞察 ✅
- **无需等待120s才能看到结果**

#### 方案3：智能缓存策略 ⭐⭐⭐⭐⭐

**缓存级别设计**：

**L1缓存：精确匹配**
```typescript
const cacheKey = `insight_${tableName}_${columnHash}`;
if (cache.has(cacheKey) && !cache.isStale(cacheKey)) {
  return cache.get(cacheKey); // 0ms 返回
}
```

**L2缓存：相似数据集复用**
```typescript
// 相同列结构的数据集可以复用部分洞察
const similarKey = `schema_${columnSignature}`;
if (cache.has(similarKey)) {
  const template = cache.get(similarKey);
  return adaptInsightsToNewData(template, currentData); // 5s 返回
}
```

**L3缓存：增量更新**
```typescript
// 数据清洗后，只重新生成受影响的洞察
const affected = detectAffectedInsights(cleaningOperation);
return {
  ...cachedInsights.filter(i => !affected.includes(i.id)),
  ...regenerateInsights(affected) // 只生成10% 的洞察
};
```

**预期效果**：
- 首次加载：120s
- 刷新页面：**< 1s**（L1缓存）
- 数据清洗后：**10-20s**（L3增量）

#### 方案4：并行优化 ⭐⭐⭐

**当前流程**（串行）：
```
文件上传 → DuckDB Ingest (1s) 
  → 清洗建议生成 (5s) 
    → 等待用户切换Tab
      → 洞察建议生成 (120s)
```

**优化流程**（并行）：
```
文件上传 → DuckDB Ingest (1s)
          ├─→ 清洗建议生成 (5s)
          └─→ 洞察建议预生成 (120s 后台)
```

**实施**：
```typescript
// 在 useDataLoader 中触发
useEffect(() => {
  if (tableName) {
    // 清洗建议（前台）
    generateCleaningSuggestions(tableName);
    
    // 洞察建议（后台）
    prefetchInsights(tableName).then(insights => {
      cache.set(`insight_${tableName}`, insights);
      toast.success('洞察分析已就绪');
    });
  }
}, [tableName]);
```

**用户体验**：
- 用户切换到"探索"Tab时 → **洞察已生成**，0s等待 ✅

|---------|---------|------|---------|
| 基础统计 | `deepseek-lite` | 10s | 3-5s |
| 相关性分析 | `deepseek-chat` | 30s | 15-20s |
| 复杂预测 | `deepseek-reasoner` | 120s | 60-90s |

**实施**：
```typescript
const insights = await Promise.all([
  askAI(basicPrompt, { model: 'deepseek-lite', timeout: 10000 }),
  askAI(correlationPrompt, { model: 'deepseek-chat', timeout: 30000 }),
  askAI(advancedPrompt, { model: 'deepseek-reasoner', timeout: 120000 })
]);
```

**成本优化**：
- Lite模型：$0.0001/1K tokens
- Chat模型：$0.0003/1K tokens
- Reasoner模型：$0.001/1K tokens
- **总成本降低 50%**
