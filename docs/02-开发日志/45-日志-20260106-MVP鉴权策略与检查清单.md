### 2.2 定义 AI 鉴权策略变更 (MVP)
- **文档创建**: [34-设计-MVP阶段AI鉴权策略变更.md](../01-架构设计/34-设计-MVP阶段AI鉴权策略变更.md)
- **策略调整**:
  - **移除**: MVP 阶段也不再允许用户输入自定义 API Key（避免“套壳”感）。
  - **保留**: 代码层面保留 Key 输入逻辑，通过 **Feature Flag (特征开关)** 隐藏。
  - **新增**: 所有请求强制走后端代理，使用系统托管的兜底 Key + 邀请码鉴权。
- **风险评估**:
  - 识别了“单 Key”并发限制与成本失控风险。
  - 制定了后端限流、前端防抖、人工监控的缓解策略。
  - 确认后端 Proxy 代码已具备基础能力，决定暂不引入复杂的“多 Key 轮询”机制。
