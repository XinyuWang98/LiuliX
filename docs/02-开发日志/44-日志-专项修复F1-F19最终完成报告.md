- **F-04 (建议卡片边框)**: 统一了 `SuggestionCard` 的 `glass-border` 样式。
- **F-06 (图片预览水印)**: 在 `ImagePreviewModal` 右下角添加了灰阶、半透明的 LiuliX Logo 水印。

- **F-13 (代码块高度)**: 将硬编码的 `max-height` 替换为 CSS 变量 `--code-block-max-height`。
- **F-14 & F-15 (侧边栏状态栏)**: 修复了收起状态下的对齐问题，优化了展开后的垂直堆叠间距。

- **F-11 (审计流程简化)**:
