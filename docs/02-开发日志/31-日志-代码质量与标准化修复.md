## 2. 详细变更

### 2.1 修复 Python 生成代码语法错误 (P0)
- **问题**: AI 生成的代码出现双重引号（如 `column = ''value''`），导致运行失败。
- **根因**: L2 Prompt 模板自带引号，且 `renderTemplate` 简单拼接再次添加引号。
- **修复**:
  1. **模板层**: 修改 10 个 L2 Prompt (`worker_*.ts`)，移除模板中的引号。
  2. **逻辑层**: 重写 `src/services/insights/inflater.ts`，实现智能类型转换（自动处理 String, Number, Boolean, Array, None）。

### 2.2 列名校验标准化 (P1/P2)
- **背景**: 两个模块各自维护一套列名校验逻辑，存在代码重复。
- **行动**:
  1. 新建 `src/utils/columnValidator.ts`，封装 `validateColumnNamesInSQL` 和 `validateColumnsExist`。
  2. **清洗模块迁移**: `aiCleaningService.ts` 移除 23 行独立实现，改用公共工具。
  3. **洞察模块迁移**: `useInsightLoaderV2.ts` 移除 30 行内联代码，改用公共工具。

### 2.3 其他修复
- **配置语法**: 修复了用户添加的 8 个 L2 Worker 能力包配置中缺少逗号的语法错误。
- **隐私合规**: 清洗模块现在正确响应用户的 `send_raw` 隐私设置。
