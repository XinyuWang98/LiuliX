## 1. 用户交互场景（最终确认版）

### 场景1：AI 建议模式（预加载执行）

**用户路径**:
```
用户打开"洞察分析"模块
  ↓
后台触发：AI批量生成 3-5 条洞察代码
  ↓
后台执行：Pyodide串行执行代码 → Base64图片 + 结果文本
  ↓
缓存结果到 analysisCache.insight
  ↓
用户点击某个建议卡片 ⚡
  ↓
从缓存读取 → 立即展示图表 (0延迟)
  ↓
用户点击"采纳"按钮 → 保存到证据池
```

**关键技术**:
- ✅ 使用真实AI生成代码（非幻觉数据）
- ✅ Pyodide执行代码（浏览器内Python）
- ✅ 输出Base64图片 + JSON数据
- ✅ IndexedDB缓存（刷新后可恢复）

---

### 场景2：对话模式（实时执行）

**用户路径**:
```
用户在对话框输入："分析年龄分布趋势"
  ↓
AI生成可执行代码
  ↓
Pyodide实时执行 → Base64图片 + 结果
  ↓
展示结果（1-2秒延迟）
  ↓
用户点击"采纳" → 保存到证据池
```

## 🐛 P0测试问题记录

### Issue #1: Pyodide环境中df未定义

**错误日志**：
```
NameError: name 'df' is not defined
```

**原因**：
- AI生成的代码使用全局变量`df`
- Pyodide环境未加载数据

**解决方案**：
- 执行前将采样数据加载到Pyodide的`df`变量
- 或修改Prompt让AI生成自包含代码


## 6. 风险与缓解（修订版）

| 风险 | 影响 | 缓解方案 |
|------|------|----------|
| Matplotlib未加载 | 无法生成图表 | worker.ts 增加 `pyodide.loadPackage('matplotlib')` |
| 执行时间过长 (5-10秒) | 用户焦虑 | 显示Loading进度条 + "正在分析中..." |
| AI生成代码语法错误 | 执行失败 | 捕获异常 → 重试一次 → 失败后跳过该建议 |
| Base64图片过大 (\u003e1MB) | IndexedDB存储慢 | 限制图表分辨率（dpi=72） |
| Pyodide Runtime大 (10MB) | 首次加载慢 | 已在App.tsx预加载 ✅ |
