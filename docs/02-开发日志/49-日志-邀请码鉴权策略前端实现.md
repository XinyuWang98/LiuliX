# 2026-01-07 邀请码鉴权策略前端实现日志

## 1. 任务目标
实现 MVP 阶段的 AI 鉴权策略，核心包括：
1.  **简化云端模式配置**：去除用户侧 API Key 填写，改用后端内置 DeepSeek API。
2.  **邀请码前置拦截**：在文件上传前检查邀请码状态，强制未激活用户进行激活。
3.  **Feature Flag 控制**：通过 `ENABLE_INVITE_CODE_GATE` 控制功能开关（开发/生产隔离）。

## 2. 核心变更详情

### 2.1 UI/UX 调整 (`APISettingsSimple.tsx`)
- **移除敏感字段**：删除了云端模式下的 `ApiKeyInput` 组件。
- **文案优化**：更新为“使用平台提供的 AI 服务，无需配置 API Key”。
- **模式明确化**：
  - **本地模式**：强调“隐私安全、无限制、免费”。
  - **云端模式**：强调“内置服务、消耗额度”。

### 2.2 流程拦截 (`FileUploader.tsx`)
- **拦截时机**：在 `handleFiles` 和 `openFileDialog` 入口处添加 `checkInviteCodeGate`。
- **状态管理**：引入 `pendingFiles` 状态，支持用户激活邀请码后自动继续上传流程，无需重新选择文件。
- **交互反馈**：未激活用户点击上传 -> 弹出 `InviteCodeModal` -> 激活成功 -> 自动开始上传。

### 2.3 国际化完善
- 同步更新了 `zh-CN` 和 `en-US` 的 `settings.ts`，新增了 `cloudModeDescNew`, `modeSelection` 等 10+ 个键值。
- 修复了 `i18n.ts` 类型定义，确保 TypeScript 编译通过。

## 3. 验证结果
- **编译检查**：TypeScript 编译通过，无类型错误。
- **浏览器验证**：
  - 设置 `ENABLE_INVITE_CODE_GATE=true` 后，点击上传正确弹出邀请码弹窗。
  - 激活邀请码后，功能恢复正常。
  - 云端模式配置页不再显示 API Key 输入框。

## 4. 重要反馈与架构调整 (Critical)

### 4.1 用户反馈
用户指出：“**不是在浏览器中使用特征开关，你的特征开关不是应该集成在后端服务器吗？**”

### 4.2 现状分析
当前 Feature Flag (`src/config/featureFlags.ts`) 为纯前端实现，依赖构建时环境变量或 `localStorage` 覆盖。这在 MVP 阶段（纯客户端应用）是可行的，特别是考虑到 DataPrism 的“本地优先”架构。

### 4.3 后续行动计划 (P0)
虽然当前前端实现已满足功能需求，但为了防止绕过和统一管理，计划：
1.  **后端集成**：在 `server/index.js` 或独立配置服务中暴露 Feature Flags 接口。
2.  **前端同步**：应用启动时从后端拉取最新 Feature Flags 配置。
3.  **双重验证**：后端 AI 代理接口 (`/api/chat`) 需同步校验 `ENABLE_INVITE_CODE_GATE` 状态，拒绝未授权请求（即使用户绕过了前端检查）。
