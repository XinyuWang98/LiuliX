# 2026年1月8日 AI设置优化与文档体系构建

## 1. 背景与目标
为了降低用户使用门槛并明确产品隐私策略，今天重点优化了 AI 设置页面，并构建了完善的用户白皮书体系。

## 2. 核心变更

### 2.1 AI 设置 UI 简化
- **移除 API Key 输入框**：MVP 阶段简化交互，隐藏复杂的 API Key 配置。
- **Ollama 优先**：推广本地模式作为首选，实现"零云依赖"。
- **试用模式限制**：确认后端已实施邀请码 20 次总调用限额，防滥用。
- **UI 文案优化**：明确区分"本地模式（离线）"与"云端模式（试用/脱敏）"。

### 2.2 用户白皮书体系
创建了 `whitepaper/` 目录，包含三份核心文档：
1. **[零云依赖教程](./../04-技术专题/📖零云依赖教程-Ollama部署.md)**：Ollama 安装与配置指南。
2. **[API Key 说明](./../04-技术专题/⚠️API-Key说明与限制.md)**：明确试用额度与升级策略。
3. **[数据脱敏策略](./../04-技术专题/🔒数据脱敏策略说明.md)**：详细阐述"自动脱敏"（元数据）与"原始数据"两种模式的区别。

### 2.3 文档入口规划
制定了在网页端添加文档入口的方案：
- **Header**: 添加"帮助"按钮（Settings 旁边）。
- **Footer**: 添加"文档"列，提供完整导航。

### 2.4 功能实现细节
- **i18n**: 更新了 `zh-CN/common.ts` 和 `en-US/common.ts`，添加 `help` 和 `docs` 翻译键。
- **Privacy Mode**: 代码层面已支持 `auto_sanitize` 和 `send_raw` 两种模式，文档与之对齐。
