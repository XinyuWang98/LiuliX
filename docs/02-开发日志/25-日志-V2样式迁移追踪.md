## 2. 样式检查清单

每个模块迁移时，必须逐项核对：

### 2.1 玻璃态容器
- [ ] 背景色使用 `var(--glass-surface)` 而非硬编码
- [ ] 模糊度使用 `var(--blur-medium)` (16px) 或 `var(--blur-heavy)` (30px)
- [ ] 边框使用 `var(--glass-border)` 而非 `var(--border)`
- [ ] 圆角使用 `var(--radius-l)` 或 `var(--radius-xl)`

### 2.2 高亮与交互
- [ ] 高亮色使用蓝色 `rgba(10, 132, 255, 0.08/0.15)` 而非黄色
- [ ] hover 效果使用 `var(--bg-hover)` 或 `rgba(255, 255, 255, 0.03)`
- [ ] 选中态使用 `var(--primary)` 相关变量

### 2.3 字体与文本
- [ ] 字体大小使用 `var(--fs-sm)` / `var(--fs-md)` / `var(--fs-lg)`
- [ ] 文本颜色使用 `var(--text-primary)` / `var(--text-secondary)` / `var(--text-tertiary)`
- [ ] 等宽字体使用 `var(--font-mono)` 而非硬编码

### 2.4 微型图与图表
- [ ] 背景色使用 `var(--primary)` (蓝色)
- [ ] 柱状图透明度约 80%
- [ ] hover 时 opacity 提升至 100%

### 2.5 代码合规
- [ ] 无硬编码颜色值
- [ ] 无魔法数字（像素值定义为常量）
- [ ] 中文注释完整
- [ ] i18n 覆盖所有用户文案

## 4. 迁移操作指南

### 4.1 新模块迁移步骤

1. **检查现有 liulix 组件**
   ```bash
   # 查看可用组件
   ls src/components/common/liulix/
   ```

2. **优先使用 liulix 类**
   ```tsx
   // ✅ 推荐
   <div className="liuli-glass">...</div>
   
   // ❌ 不推荐
   <div style={{ background: 'rgba(...)' }}>...</div>
   ```

3. **次选使用 CSS 变量**
   ```css
   .my-container {
       background: var(--glass-surface);
       backdrop-filter: blur(var(--blur-medium));
       border: 1px solid var(--glass-border);
   }
   ```

4. **浏览器验证**
   - 对比 http://localhost:5173/#/design 效果
   - 检查玻璃态透明度和模糊
   - 确认颜色无硬编码
