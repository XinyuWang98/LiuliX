# 开发日志：洞察模块图片统一管理功能实施

**日期**: 2026-01-05  
**状态**: ✅ 已完成  
**作者**: Antigravity

## 1. 场景与目标

在之前的版本中，洞察模块（InsightCardV2、InsightTreeNode 等）和报告模块（ReportCellReadOnly、ReportSummary）中的图表图片样式不统一，存在以下问题：
- **硬编码样式**: 多处存在 `max-height`、`width` 的硬编码，违反全局规则 1。
- **布局不一致**: 图片在不同场景下的缩放模式（object-fit）和对齐方式不统一。
- **交互匮乏**: 用户无法点击图片放大查看细节，也无法直接下载图表图片。
- **由于 431 错误**: Base64 图片过大导致 HTTP 请求头溢出，已在 `imageUtils.ts` 中修复，但需要统一的展示组件。

**目标**:
1. 建立全局图片 CSS 变量系统。
2. 创建统一的 `ChartImage` 组件，集成加载、错误、全屏预览、下载等功能。
3. 替换全项目中所有洞察图表的原生 `<img>` 标签。

## 2. 实施过程

### 第一阶段：基础 CSS 变量系统 (Tokens)
- 创建 `src/styles/tokens/_images.css`，定义尺寸、间距、圆角、阴影及交互状态（Hover Scale 等）变量。
- 在 `tokens/index.css` 中引入。
- 采用分层最大高度：卡片场景 (`400px`) vs 报告场景 (`600px`)。

### 第二阶段：高级变量扩展
- 增加骨架屏（Skeleton Shimmer）动画变量。
- 增加加载失败（Error State）样式变量。
- 增加响应式变体（Mobile/Tablet/Desktop）。

### 第三阶段：交互组件开发
- **ChartImage 组件**:
  - 支持 `variant="card" | "report" | "thumbnail"`。
  - 集成 `ImagePreviewModal` 实现点击全屏。
  - 悬停工具栏（Toolbar）：提供下载按钮和全屏按钮。
  - 图片加载状态监听，显示骨架屏动画。
- **ImagePreviewModal 增强**:
  - 添加下载按钮，支持保存原图到本地。
  - 优化布局，关闭按钮与下载按钮并列。

### 第四阶段：全量替换与验证
- 替换 `InsightCardV2.tsx`、`InsightTreeNode.tsx`、`ReportCellReadOnly.tsx` 和 `ReportSummary.tsx` 中的 `<img>` 标签。
- 运行 `npm run build` 确保无编译错误。
- 浏览器端 E2E 验证：悬停工具栏出现、点击全屏模态框正常、下载功能有效。
