## 🚀 关键里程碑

### 1. 硬编码清理 (Strict Mode Implementation)

为了解决代码库中残留的中文变量和 UI 硬编码，我们开发并优化了检测工具。

*   **创建脚本**: `scripts/check-hardcoded.ts`，支持严格模式过滤。
*   **优化策略**: 排除 AI Prompts, Infrastructure Log, Tool Definitions 等非用户界面文本。
*   **清理成果**:
    *   **初始检出**: 635 处。
    *   **最终剩余**: **367** 处 (减少 42%)。
    *   **核心修复**: 彻底移除了 `useInsightLoaderV2`, `useInsightRefresh`, `insightGenerator` 等核心逻辑文件中的中文变量 (`有效列名` -> `validColumns` 等)。
*   **交付物**: 
    *   [172-专题-硬编码文本检测报告.md](../04-技术专题/172-专题-硬编码文本检测报告.md)

### 2. i18n 合规性审计

*   **缺失修复**: 修复了 `zh-CN` (28个) 和 `en-US` (46个) 缺失的 Key，特别是 `analysis` 和 `cleaning` 模块。
*   **类型修复**: 修复了 `i18n.ts` 类型定义，确保与 `.ts` 翻译文件同步。
*   **工程化**: 将 `check:i18n` 集成到项目启动流程，杜绝未来回归。

### 3. 代码复用性审计 (Phase 2)

*   **CSS 变量**: 确认 `StatsPanel` 和 `VirtualDataGrid` 已完全迁移至 CSS 变量系统。
*   **文档清理**: 从项目概览中移除了已废弃的 "V2 样式迁移" 章节，确认 V2 样式系统已成为默认标准。
