## 1. 任务背景

用户反馈在英文模式下浏览器标题仍显示中文，且项目卡片的时间显示（如"1周前"）未正确国际化。同时，为了优化首页和底部的视觉体验，需要移除 Roadmap 清单的小圆点及暂时隐藏 GitHub 入口。

## 2. 变更详情

### 2.1 浏览器标题国际化修复 (Fixed)

*   **问题**: 英文模式下浏览器标签页标题显示 "LiuliX - 数据探索平台"。
*   **根因**: 
    1.  `src/locales/en-US/index.ts` 中硬编码了旧版的 `common` 对象，未引用 `common.ts` 模块，导致新添加的 `pageTitle` 键值对不可见。
    2.  `App.tsx` 中的 `useEffect` 依赖项不完整，语言切换时未触发更新。
*   **修复**:
    *   重构 `src/locales/en-US/index.ts`，改为从 `./common` 模块导入 `common`, `data`, `nav`, `sidebar` 对象。
    *   在 `src/locales/en-US/common.ts` 中补充缺失的 `sidebar` 导出及 `featureInDev` 等键值。
    *   修改 `App.tsx`，在 `useEffect` 依赖数组中显式添加 `language` 对象，确保语言切换时强制刷新 `document.title`。

### 2.2 项目卡片时间显示国际化 (Fixed)

*   **问题**: 英文模式下项目卡片显示 "1周前" 等中文时间描述。
*   **修复**:
    *   `ProjectCard.tsx` 中正确解构 `useI18n()` 返回的 `language` 对象。
    *   将 `language.code` ('zh-CN' | 'en-US') 传递给 `formatRelativeTime` 函数。
    *   更新 `src/utils/time.ts`，使用 `Intl.RelativeTimeFormat` API 替代硬编码的中文时间逻辑，实现原生国际化支持。

### 2.3 UI/UX 细节优化 (Polished)

*   **Roadmap 视觉优化**:
    *   修改 `Roadmap.css`，移除 `roadmap-features li::before` 的伪元素样式，去掉了列表项前的小圆点，使界面更加简洁。
*   **社区入口调整**:
    *   暂时注释掉 `FeedbackSection.tsx` 和 `Footer.tsx` 中的 GitHub 链接与卡片，聚焦 Discord 社区引导。
    *   调整 `FeedbackSection.css`，在仅显示 Discord 卡片时保持居中对齐。
