# 错误分析卡片：问题#20 UI重叠遮挡严重

## 1. 问题背景
- **现象**：用户反馈“下方输入框和中间数据探索栏的内容会产生重叠”，影响用户体验。
- **截图证据**：[Uploaded Image] 显示底部悬浮的 "Ask AI" 输入栏遮挡了数据清洗建议表格的底部行和翻页控件。
- **严重程度**：**P1 (阻塞体验)**。尽管可以通过滚动看到内容，但悬浮遮挡导致视觉混乱，且可能误触，属于严重的 UI/UX 缺陷。

## 2. 根因分析
- **CSS 定位机制**：
  在 `ExplorationFlow.css` 中，`.chat-input-wrapper` 使用了 `position: absolute; bottom: 30px;`。
  这意味着它脱离了文档流，强制悬浮在 `.scroll-container` 之上。
- **Padding 不足或无效**：
  虽然 `.content-wrapper` 设置了 `padding-bottom: 140px` 试图预留空间，但在在不同屏幕分辨率或内容高度动态变化下，悬浮元素始终覆盖在视口底部，导致用户必须额外大幅滚动才能看到被遮挡的内容，体验极差。

## 3. 解决方案（拟定）

**方案：改为 Flex 垂直布局（移除悬浮）**

将布局从“层叠悬浮”改为“垂直分块”，让输入框占据独立的底部空间，不再遮挡上方内容。

**代码变更计划**：
1.  **ExplorationFlow.css**:
    - `.chat-input-wrapper`: 移除 `position: absolute`，改为 `position: relative` (或默认 flex item)。
    - `.chat-input-wrapper`: 添加顶部边框或阴影以区分区域。
    - `.content-wrapper`: 移除巨大的 `padding-bottom: 140px`，改为正常的 `padding-bottom: 20px`。
2.  **ExplorationFlow.tsx**:
    - 确保 `scroll-container` 和 `chat-input-wrapper` 同级且都在 `right-panel-wrapper` (flex-col) 内部。

**预期效果**：
- 输入框固定在屏幕底部（Footer）。
- 内容区域自动适应剩余高度。
- 滚动到底部时，内容完全可见，绝无遮挡。
