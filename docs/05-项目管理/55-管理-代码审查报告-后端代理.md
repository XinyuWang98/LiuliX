## ❌ 严重违规问题 (P0)

### 1. **铁律 #3 违反：中文注释与命名**

**违规文件**: `server/index.js`

**问题描述**:  
- 所有变量名、函数名使用英文（如 `app`, `PORT`, `targetUrl`, `config`）
- 部分注释使用中文，但不彻底

**违规代码示例**:
```javascript
const app = express();              // ❌ 应为: const 应用 = express();
const PORT = process.env.PORT || 3001;  // ❌ 应为: const 端口 = process.env.PORT || 3001;

app.use(cors({
    origin: 'http://localhost:5173', // ❌ origin 应为 来源
    methods: ['GET', 'POST', 'OPTIONS'], // ❌ methods 应为 方法
    allowedHeaders: ['Content-Type', 'Authorization', 'x-api-key'] // ❌ allowedHeaders 应为 允许的请求头
}));

app.post('/api/proxy', async (req, res) => { // ❌ req/res 应为 请求/响应
    const { targetUrl, method = 'POST', headers = {}, data } = req.body; // ❌ 全部英文
    // ...
});
```

**全局规则原文**:
> 3. **中文注释与命名**  
>    所有注释、变量名、函数名、日志信息必须用中文。

**影响范围**: 整个 `server/index.js` 文件  
**严重程度**: 🔴 P0 - 违反核心铁律 #3
