## 可能的修复方案

### 方案1: Map初始化问题
如果Map一直为空：
```typescript
// 可能需要在初始化后强制触发一次更新
useEffect(() => {
    // 强制刷新组件
    setFileAIStatus(prev => new Map(prev));
}, []);
```

### 方案2: Key不匹配
如果key对不上：
```typescript
// 统一使用fileName作为key
newMap.set(file.data.fileName, { status: 'ready' });
```

### 方案3: 持久化时机问题
如果localStorage写入时机不对：
```typescript
// 在setFileAIStatus回调中同步写入
setFileAIStatus(prev => {
    const newMap = new Map(prev);
    newMap.set(file.id, { status: 'ready' });
    
    // 立即持久化
    const obj = Object.fromEntries(newMap);
    localStorage.setItem('fileAIStatus', JSON.stringify(obj));
    
    return newMap;
});
```
