### 任务4: 数据预缓存机制 🚀

**优先级**: P1  
**工时**: 3小时  
**文件**: `src/hooks/useDataCache.ts` (新建)

**目标**: 切换文件延迟从50ms→<1ms

**实施步骤**:

1. **创建useDataCache Hook**
   ```typescript
   export function useDataCache() {
       const cache = useRef<Map<string, any[]>>(new Map());
       
       const getCachedData = async (tableName: string) => {
           if (cache.current.has(tableName)) {
               return cache.current.get(tableName)!;
           }
           
           const engine = DuckDBEngine.getInstance();
           const data = await engine.queryChunk(tableName, 0, 1000);
           cache.current.set(tableName, data);
           return data;
       };
       
       return { getCachedData };
   }
   ```

2. **集成到useSuggestionGeneration**
   ```typescript
   const { getCachedData } = useDataCache();
   
   // 替换原有查询
   data = await getCachedData(tableName);
   ```

3. **添加缓存失效策略**
   ```typescript
   const invalidateCache = (tableName: string) => {
       cache.current.delete(tableName);
   };
   ```

   ```typescript
   export class PriorityQueue extends ConcurrencyQueue {
       addHigh(task: Task<any>) {
           this.queue.unshift({ task, resolve, reject });
           this.process();
       }
       
       addLow(task: Task<any>) {
           this.queue.push({ task, resolve, reject });
           this.process();
       }
   }
   ```
