   - AI洞察次数（最强压迫）
   - 报告导出次数（关键时刻付费）
   - 数据规模限制（自然痛点）

3. **福利价策略**:
   - 前1000名用户终身¥99锁定
   - 后续用户阶梯涨价（每年+10%）

**对后续规划的影响**:
- **P2任务**（已规划）：MVP邀请码系统
- **新增P2任务**：定价页设计 + Stripe集成

### 见解3：MVP邀请码冷启动（可直接实施 🎫）

**文档**: [47-技术专题-MVP邀请码冷启动方案.md](../04-技术专题/47-技术专题-MVP邀请码冷启动方案.md)

**核心洞察**:
1. **离线JWT方案**:
   - 无需后端数据库
   - 公钥硬编码验证
   - 契合"本地优先"理念

2. **地区化配额**:
   - 黑金码：30个（中国）+ 20个（全球）
   - 早鸟码：1000个 + 1000个
   - 社区码：无限（按批次）

3. **防刷机制**:
   - 浏览器指纹 + IndexedDB
   - 单码单次激活

**对后续规划的影响**:
- **可立即实施**（技术方案完整）
- 优先级：P2（MVP 100%后执行）
- 工作量：6-8小时
