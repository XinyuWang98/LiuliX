## 🔧 优化方案

### 方案 A：流式膨胀+执行（推荐）

**核心思路**：每个任务膨胀完成后立即加入执行队列

#### 实现代码

```typescript
// useInsightLoaderV2.ts

// 替换 Line 233-244
const inflateStartTime = performance.now();
logger.log('AI服务', `🚀 [性能追踪] 开始流式膨胀+执行`);

// 🆕 创建流式处理管道
const processedNodes: InsightNode[] = [];
const pLimit = (await import('p-limit')).default;
const inflateLimit = pLimit(2); // 膨胀并发度
const executeLimit = pLimit(2); // 执行并发度

// 🆕 流式处理：膨胀完立即执行
const processingPromises = recommendations.map((rec, index) =>
    inflateLimit(async () => {
        // 1. 膨胀单个任务
        const node = await inflateSingleRecommendation(rec, tableName);
        
        if (!node) return null;
        
        // 2. 立即加入执行队列（不等待其他膨胀）
        return executeLimit(async () => {
            logger.log('AI服务', `[流式] 任务 ${index+1} 膨胀完成，立即执行`);
            
            const executeStart = performance.now();
            await executeSingleNode(node, ...);
            const executeDuration = performance.now() - executeStart;
            
            logger.log('AI服务', `[流式] 任务 ${index+1} 执行完成 (${executeDuration.toFixed(1)}ms)`);
            
            // 3. 流式更新 UI
            onNodeComplete?.(node);
            
            return node;
        });
    })
);

// 等待全部完成
const results = await Promise.all(processingPromises);
insightNodes = results.filter(node => node !== null);

const totalDuration = (performance.now() - inflateStartTime) / 1000;
logger.log('AI服务', `✅ [性能追踪] 流式处理完成: ${insightNodes.length} 个节点 (${totalDuration.toFixed(1)}s)`);
```

### 方案 B：异步启动执行器（简单）

**核心思路**：膨胀开始后，立即启动监听器等待节点完成

```typescript
// 🆕 创建节点队列和执行器
const nodeQueue: InsightNode[] = [];
let isExecuting = false;

// 🆕 后台执行器（异步）
const startBackgroundExecutor = async () => {
    while (true) {
        if (nodeQueue.length === 0) {
            await sleep(100); // 等待新节点
            continue;
        }
        
        const node = nodeQueue.shift()!;
        await executeSingleNode(node, ...);
        onNodeComplete?.(node);
    }
};

// 启动后台执行器
startBackgroundExecutor(); // 不await，异步执行

// 膨胀并加入队列
const inflatePromises = recommendations.map(rec =>
    limit(async () => {
        const node = await inflateSingleRecommendation(rec, tableName);
        if (node) {
            nodeQueue.push(node); // 立即加入队列
            logger.log('AI服务', `节点已加入执行队列: ${node.title}`);
        }
        return node;
    })
);

await Promise.all(inflatePromises);
```

## ⚠️ 实施注意点

### 1. 并发控制

两层并发可能冲突：
- 膨胀并发：2
- 执行并发：2

**总并发**：理论上 2×2 = 4，但实际可能只有 2-3

**建议**：
```typescript
const inflateLimit = pLimit(2);
const executeLimit = pLimit(1); // 先串行执行，避免过载
```

---

### 2. 错误处理

单个任务失败不应影响其他：

```typescript
try {
    await executeSingleNode(node, ...);
} catch (error) {
    logger.error('AI服务', `任务执行失败: ${node.title}`, { error });
    node.error = error.message;
}
```
