## 🔍 可行性分析

### 1. 哪些分析可以规则预执行？

#### ✅ 高确定性分析（总是有用）

| 分析类型                   | 规则判断条件                | 执行成本 |
| :------------------------- | :-------------------------- | :------: |
| **数据概览**               | 总是执行                    |    低    |
| **缺失值分析**             | 总是执行                    |    低    |
| **数据分布**（数值列）     | `if (hasNumericColumn)`     |    中    |
| **描述性统计**（数值列）   | `if (hasNumericColumn)`     |    低    |
| **Top N 排行榜**（类别列） | `if (hasCategoricalColumn)` |    中    |

**预估执行时间**：3-5 个基础分析，总计 **3-5 秒**

---

#### ⚠️ 中确定性分析（需判断）

| 分析类型       | 规则判断条件                                    | 有用性判断            |
| :------------- | :---------------------------------------------- | :-------------------- |
| **相关性分析** | `if (numericColumns.length >= 2)`               | 相关系数 > 0.3 才展示 |
| **时间趋势**   | `if (hasDateColumn && hasNumericColumn)`        | 数据点 >= 10 才有意义 |
| **分组聚合**   | `if (hasCategoricalColumn && hasNumericColumn)` | 分组数 < 20 才清晰    |

**筛选策略**：
- 执行后计算"有用性评分"
- 评分 < 阈值 → 不展示（或放到"更多分析"折叠区）

---

#### ❌ 低确定性分析（留给 AI）

| 分析类型     | 为什么需要 AI？                          |
| :----------- | :--------------------------------------- |
| **聚类分析** | 需要判断最优簇数（k），需要领域知识      |
| **回归分析** | 需要选择因变量和自变量，需要业务理解     |
| **决策树**   | 需要选择目标变量，需要预测目标理解       |
| **时序分解** | 需要判断周期性（日/周/月），需要业务知识 |

**策略**：让 AI 基于基础分析结果推荐高级分析

### 2. 如何判断分析是否有用？

#### 方法 A：统计显著性判断

```typescript
function evaluateInsightValue(insight: InsightNode): number {
  switch (insight.promptId) {
    case 'worker-correlation-v1':
      // 提取相关系数
      const r = extractCorrelation(insight.result);
      if (Math.abs(r) < 0.3) return 0;  // 弱相关，不展示
      if (Math.abs(r) > 0.7) return 100; // 强相关，高优先级
      return 50; // 中等相关
      
    case 'worker-distribution-v1':
      // 检查分布是否"有趣"（非均匀分布）
      const entropy = calculateEntropy(insight.result.data);
      return entropy > 1.5 ? 80 : 30;
      
    case 'worker-groupby-v1':
      // 检查分组数量
      const groupCount = insight.result.data.length;
      if (groupCount > 20) return 0;  // 太多分组，不清晰
      if (groupCount < 3) return 20;  // 太少分组，无意义
      return 70; // 合适的分组数
  }
}
```

#### 方法 B：数据特征判断（更快）

```typescript
function shouldExecuteAnalysis(
  promptId: string,
  dataFeatures: DataFeatures
): boolean {
  const rules = {
    'worker-correlation-v1': 
      dataFeatures.numericColumns >= 2,
    
    'worker-trend-v1': 
      dataFeatures.hasDateColumn && dataFeatures.numericColumns >= 1,
    
    'worker-groupby-v1': 
      dataFeatures.categoricalColumns >= 1 && 
      dataFeatures.numericColumns >= 1 &&
      dataFeatures.categoryCardinality < 20, // 类别数不超过 20
  };
  
  return rules[promptId] || false;
}
```

**优势**：
- 执行前就知道是否有用，避免浪费计算
- 基于数据特征，非常快速（<100ms）

**推荐**: ✅ **方法 B**（执行前判断，更高效）

async function loadInsightsV3(columns, rowCount, tableName) {
  const startTime = performance.now();

  //   { promptId: 'worker-stats-v1', params: { column_name: 'salary' } },
  //   ...
  // ]

  const basicNodes = await inflateRecommendations(basicAnalyses, tableName);

  setInsightNodes(basicNodes);

  // ========== Phase 2: AI 增强推荐（后台异步）==========
  setTimeout(async () => {
    // 2.1 构建增强 Prompt（基于基础分析结果）
    const enhancedPrompt = buildEnhancedPrompt(basicNodes, dataFeatures);
    
    // 2.2 调用 AI
    const aiResponse = await invokeAI(enhancedPrompt);
    const { drillHints, advancedAnalyses } = parseEnhancedResponse(aiResponse);
    
    // 2.3 注入 drillHint 到基础分析
    basicNodes.forEach(node => {
      const hint = drillHints.find(h => h.baseInsightId === node.id);
      if (hint) {
        node.drillDownActions = [hint];
      }
    });
    
    // 2.4 执行高级分析
    const advancedNodes = await inflateRecommendations(advancedAnalyses, tableName);
    await executeBatchNodes(advancedNodes, { tableName, priority: 'low' });
    
    // 2.5 追加到列表
    setInsightNodes([...basicNodes, ...advancedNodes]);
    
  }, 100);
}

### 数据特征分析函数

```typescript
async function analyzeDataFeatures(tableName: string): Promise<DataFeatures> {
  const schema = await getTableSchema(tableName);
  const db = DuckDBEngine.getInstance();
  
  // 分析列类型
  const numericCols = schema.filter(c => isNumeric(c.type));
  const categoricalCols = schema.filter(c => isCategorical(c.type));
  const dateCols = schema.filter(c => isDate(c.type));
  
  // 分析类别列基数（避免高基数列）
  const categoryCardinality: Record<string, number> = {};
  for (const col of categoricalCols) {
    const result = await db.runQuery(
      `SELECT COUNT(DISTINCT ${col.name}) as cnt FROM ${tableName}`
    );
    categoryCardinality[col.name] = result[0].cnt;
  }
  
  return {
    numericColumns: numericCols.length,
    categoricalColumns: categoricalCols.length,
    hasDateColumn: dateCols.length > 0,
    categoryCardinality,
    schema
  };
}
```

### 规则生成基础分析

```typescript
function generateBasicAnalyses(features: DataFeatures): L1Recommendation[] {
  const analyses: L1Recommendation[] = [];
  
  // 规则 1: 数值列 → 分布 + 统计
  const numericCols = features.schema.filter(c => isNumeric(c.type));
  for (const col of numericCols.slice(0, 3)) { // 最多 3 个
    analyses.push({
      promptId: 'worker-distribution-v1',
      params: { column_name: col.name },
      reason: `查看 ${col.name} 的数据分布`
    });
  }
  
  // 规则 2: 两个数值列 → 相关性
  if (numericCols.length >= 2) {
    analyses.push({
      promptId: 'worker-correlation-v1',
      params: { col_x: numericCols[0].name, col_y: numericCols[1].name },
      reason: `分析 ${numericCols[0].name} 与 ${numericCols[1].name} 的关系`
    });
  }
  
  // 规则 3: 低基数类别列 → Top N
  const lowCardCats = features.schema.filter(c => 
    isCategorical(c.type) && 
    (features.categoryCardinality[c.name] || 0) < 20
  );
  if (lowCardCats.length > 0) {
    analyses.push({
      promptId: 'worker-topn-v1',
      params: { column_name: lowCardCats[0].name, n: 10 },
      reason: `查看 ${lowCardCats[0].name} 的 Top 10 分布`
    });
  }
  
  // 规则 4: 日期 + 数值 → 趋势
  if (features.hasDateColumn && numericCols.length > 0) {
    const dateCols = features.schema.filter(c => isDate(c.type));
    analyses.push({
      promptId: 'worker-trend-v1',
      params: { date_col: dateCols[0].name, value_col: numericCols[0].name },
      reason: `${numericCols[0].name} 随时间的变化趋势`
    });
  }
  
  return analyses;
}
```

## ⚖️ 优劣势分析

### 优势

1. **TTFI 极速**：6 秒 vs 47 秒（-87%）
2. **AI 更聪明**：基于真实分析结果推荐，而非猜测
3. **成本更低**：AI Prompt 更短（~1000 字符 vs 2236）
4. **确定性高**：基础分析总是可靠，不依赖 AI 质量
5. **向后兼容**：可以与现有 Router 模式并存

### 劣势与风险

1. **规则维护成本**
   - 需要维护"哪些分析适合规则生成"的逻辑
   - 缓解：规则相对稳定，不常变更

2. **可能推荐不相关分析**
   - 规则可能生成用户不感兴趣的分析
   - 缓解：通过"有用性评分"筛选 + 用户反馈优化

3. **无法捕捉复杂业务逻辑**
   - 规则无法理解"这是电商数据，应该关注转化率"
   - 缓解：让 AI 负责高级分析推荐（保留 AI 的智能）
