# LiuliX 端到端 (E2E) 测试方案 (Web MVP Edition V3)

**最后更新**: 2026-01-11
**Applicable Version**: MVP v1.0.16 (Web Only)
**Test Focus**: Real-world Performance, Cross-Platform Stability, Parallel Safety
**Goal**: 上线前终极验收清单 (Ultimate Launch Verification)

## 1. 测试目标
验证 LiuliX (Web 版) 在真实、复杂、低配环境下的表现。不再追求理想化的"极速"，而是追求用户可接受的"稳健"。
引入 **红绿灯分级制**：
*   🟢 **Green (Target)**: 理想性能，用户体验极佳。
*   🟡 **Yellow (Limit)**: 可接受底线，用户体验稍有等待但不流失。
*   🔴 **Red (Failure)**: 严重性能问题，需优化或拦截。

## 2. 测试环境与基准 (Baseline)

### 2.1 扩充跨平台兼容性 (Cross-Platform)
需覆盖以下真实用户场景：
1.  **High-End Mac**: M1/M2/M3 Max/Pro + Chrome (理想基准)
2.  **Standard Windows**: Intel i7/Ryzen 7 + 16GB RAM + Edge/Chrome (主流用户)
3.  **Low-End Windows**: Intel i5 + 8GB/16GB (集成显卡) (压力测试)
4.  **Browser Variant**: Safari (macOS), Firefox (兼容性检查)

### 2.2 性能预测模型 (Revised Realistic Thresholds)

| 操作                | 100万行 (Large) Green | 100万行 (Large) Yellow | 200万行 (XL) Green | 瓶颈因素               |
| :------------------ | :-------------------- | :--------------------- | :----------------- | :--------------------- |
| **CSV 解析入库**    | < 12s                 | < 20s                  | < 25s              | IO / Low-End CPU       |
| **内存占用 (Peak)** | < 1.5GB               | < 2.5GB                | < 3.0GB            | 浏览器 Tab 崩溃阈值    |
| **AI 清洗建议**     | < 12s                 | < 20s                  | < 12s              | 网络延迟 (Schema-only) |
| **L1 洞察首卡片**   | < 18s                 | < 30s                  | < 25s              | AI Stream + 采样计算   |
| **L1 洞察全完成**   | < 40s                 | < 60s                  | < 60s              | 并发 Worker 调度       |

### Phase 4: 稳定性与真实场景 (Stability & Real World) **[NEW]**

| ID        | 测试场景            | 操作步骤                            | 预期结果 (Pass Criteria)                                                       |
| :-------- | :------------------ | :---------------------------------- | :----------------------------------------------------------------------------- |
| **TC-10** | **网络异常兜底**    | 触发 Insight 时断网或 Mock 500 错误 | 1. 界面显示红色 Toast <br> 2. 原地显示 "Retry" 按钮 <br> 3. **不无限 Loading** |

| **TC-13** | **持久化恢复**      | 关闭 Tab 再重新打开                 | 1. 数据无需重新上传 (IndexedDB) <br> 2. 清洗历史保留                           |

## 6. 结论建议

*   若 **Green > 80%** 且无 **Red**: ✅ **Ready for Launch**.

*   若 **Red > 0**: 🛑 **Block Launch**.
