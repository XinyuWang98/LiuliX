# LiuliX 端到端 (E2E) 测试方案 (Web MVP Edition V3.1)

**最后更新**: 2026-01-13
**Applicable Version**: MVP v0.1.0 (Web Only)
**Test Focus**: Real-world Performance, Cross-Platform Stability, Parallel Safety, Dynamic Memory Assessment
**Goal**: 上线前终极验收清单 (Ultimate Launch Verification)

## 1. 测试目标
验证 LiuliX (Web 版) 在真实、复杂、低配环境下的表现。不再追求理想化的"极速"，而是追求用户可接受的"稳健"。
引入 **红绿灯分级制**：
*   🟢 **Green (Target)**: 理想性能，用户体验极佳。
*   🟡 **Yellow (Limit)**: 可接受底线，用户体验稍有等待但不流失。
*   🔴 **Red (Failure)**: 严重性能问题，需优化或拦截。

## 2. 测试环境与基准 (Baseline)

### 2.1 扩充跨平台兼容性 (Cross-Platform)
需覆盖以下真实用户场景：
1.  **High-End Mac**: M1/M2/M3 Max/Pro + Chrome (理想基准)
2.  **Standard Windows**: Intel i7/Ryzen 7 + 16GB RAM + Edge/Chrome (主流用户)
3.  **Low-End Windows**: Intel i5 + 8GB/16GB (集成显卡) (压力测试)
4.  **Browser Variant**: Safari (macOS), Firefox (兼容性检查)

## 3. 测试数据准备 (Test Datasets)

重点覆盖 **百万级** 数据，验证真实压力。

#### 3.1 测试策略变更
采用 **串行独占测试 (Sequential Exclusive Testing)** 模式：
1.  **单次上传**: 每次仅上传 **1个** 目标数据集。
2.  **完整测试**: 执行该数据集对应的所有测试用例（导入、清洗、洞察）。
3.  **清理重置**: 测试完成后，通过 UI 项目选择模块卡片编辑按钮 **删除** 该数据集。
4.  **循环**: 重复上述步骤直至测完所有文件。
