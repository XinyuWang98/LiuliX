## 完整功能流程

### 用户访问页面 → InsightChainFlow加载
```
1. useEffect触发loadHypotheses()
2. 检查tableName是否存在
3. 调用sampleDataForAI(tableName, 1000)
   ↓
   📊 从DuckDB采样1000行数据
   📋 记录元数据（总行数、采样行数、是否采样）
4. 调用generateHypotheses({ columns, rowCount, sampleData: 采样数据 })
   ↓
   🤖 通过localhost:5000代理调用DeepSeek API
   💡 生成3-5条分析假设
5. 转换为HypothesisCard格式并显示
```

### 失败降级机制
```
AI调用失败
  ↓
catch (AI错误)
  ↓
显示Mock假设卡片（标题带"Mock"标识）
  ↓
UI不崩溃，用户仍可交互
```
