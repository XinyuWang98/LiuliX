## 🔧 核心改动

### 1. 生成带时间戳的文件名

```typescript
// 🆕 生成带时间戳的报告文件名
const generateReportPath = () => {
    const now = new Date();
    const timestamp = now.toISOString()
        .replace(/:/g, '-')  // 替换冒号为连字符
        .replace(/\..+/, '')  // 移除毫秒部分
        .replace('T', '_');   // 替换 T 为下划线
    
    // 格式: 2026-01-15_03-40-01
    return path.resolve(
        __dirname, 
        `../docs/03-测试验证/48-测试-批量洞察分析测试报告-${REPORT_SUFFIX}-${timestamp}.md`
    );
};
```

**时间戳格式**: `YYYY-MM-DD_HH-MM-SS`
- 可排序
- 文件名安全（无特殊字符）
- 人类可读

---

### 2. 标题包含时间

```typescript
const readableTime = now.toLocaleString('zh-CN', { 
    timeZone: 'Asia/Shanghai',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit',
    hour12: false
});

let md = `# 📊 批量洞察分析测试报告 (V2) - ${readableTime}\n\n`;
```

**标题示例**:
