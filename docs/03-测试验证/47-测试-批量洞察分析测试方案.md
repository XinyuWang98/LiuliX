### 2.2 🧩 Prompt 模版与质量详情
对于每个数据集，记录每个 Prompt 的执行详情：
*   **Prompt ID**: (如 `worker-stats-v1`)
*   **Quality Score**: 质量门控分数 (0-100)
    *   **Status**: ✅ Pass / ❌ Fail
    *   **Reason**: 未通过原因 (如 "Confidence < 80")
*   **Input Params**: 输入的变量 (如 `{"column_name": "sales"}`)

### 2.3 🚨 异常日志捕获
*   **Error Type**: 错误类型 (如 `ColumnMismatch`, `ExecutionError`)
*   **Message**: 具体的错误堆栈或提示，重点捕获列名相关错误。
