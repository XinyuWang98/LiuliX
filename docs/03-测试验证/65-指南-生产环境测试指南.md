# 生产环境测试指南

> **更新时间**: 2026-01-15 03:43  
> **目的**: 使用生产构建测试，避免 StrictMode 双重渲染干扰  

---

## 🎯 为什么需要生产环境测试？

### 问题：开发环境的 StrictMode

**开发环境** (`npm run dev`)：
- ⚠️ React StrictMode 启用
- ⚠️ 组件双重渲染
- ⚠️ 双重 AI 调用
- ⚠️ 性能数据不准确

**生产环境** (`npm run build + preview`)：
- ✅ React StrictMode **自动禁用**
- ✅ 单次渲染
- ✅ 单次 AI 调用
- ✅ **真实性能数据**

### Step 1: 构建生产版本


**输出**:

**新终端窗口**:
```bash

```

**输出**:

**保持此服务器运行**，不要关闭！

### Step 3: 运行测试脚本

**另一个终端窗口**:

#### 基础用法
```bash
npx tsx scripts/batch_test_insights_single.ts zh-CN Production production
```

**参数说明**:
1. `zh-CN` - 语言（zh-CN 或 en-US）
2. `Production` - 报告后缀标签
3. `production` - **环境模式**（dev 或 production）

---

**生产环境 - 早上测试**:
```bash

```

**生产环境 - 晚上测试**:
```bash

```

**生产环境 - 优化后**:
```bash

```

## 🚨 常见问题

### Q1: 预览服务器启动失败

**错误**: `Port 4173 is already in use`

**解决**:
```bash
# 查找占用端口的进程
lsof -ti:4173 | xargs kill -9

# 重新启动
npm run preview
```

---

### Q2: 测试脚本连接失败

**错误**: `Upload input not found`

**检查**:
1. 预览服务器是否运行？
2. URL 是否正确？（http://localhost:4173）
3. 浏览器手动访问是否正常？

---

### Q3: 如何确认是否在生产环境？

**方法 1**: 查看控制台输出
```
🌍 环境模式: 生产环境 (Production Build)
🔗 测试 URL: http://localhost:4173
```

**方法 2**: 查看报告标题
```markdown
# 📊 批量洞察分析测试报告 (V2) - 2026/01/15 03:45:30
> **环境**: 生产环境 (Production Build)
```

**方法 3**: 检查 AI 调用次数
- 生产环境：每个数据集只有 1 次 AI 调用
- 开发环境：每个数据集有 2 次 AI 调用
