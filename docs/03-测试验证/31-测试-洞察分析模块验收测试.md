## 📋 验证方法说明

由于这是前端JavaScript应用，**大部分验证可通过浏览器开发者工具完成**：

### 验证工具
1. **F12 Console**: 查看日志输出（格式: `[服务名] 操作描述`）
2. **F12 Network**: 查看AI API请求（Request/Response Body）
3. **F12 Sources**: 断点调试，检查变量值
4. **React DevTools**: 查看组件state和props

### 日志规范
- ✅ **标准格式**: `[AI洞察] 解析成功 {count: 5}`
- ✅ **分组日志**: `console.group('[AI洞察] 批量洞察生成流程（双模式）')`
- ✅ **临时验证log**: 可在代码中添加`console.log('Debug:', variable)`后刷新页面

### 关键验证点
- **Prompt验证**: Network → DeepSeek API请求 → Request Body
- **响应解析**: Sources断点 → `parseBatchInsightsResponse` → 查看`insightSuggestions`数组
- **执行模式**: Console → 搜索`[AI服务] 洞察X: full模式`或`aggregated模式`
- **质量评分**: Console → 搜索`[质量门控] 评分: X/100`

**验收标准**:
- ✅ **方法1（断点查看响应）**: aiResponse包含完整JSON数组
  ```json
  [
    {
      "title": "XXX",
      "description": "XXX",
      "columns_used": ["col1", "col2"],
      "full_mode": {
        "code": "import pandas as pd\n..."
      },
      "aggregated_mode": {
        "sql": "SELECT ...",
        "viz_code": "# 基于聚合结果的可视化\n..."
      }
    }
  ]
  ```
- ✅ **方法2（控制台验证）**: 
  - 找到日志: `[AI洞察] 解析成功`，后面括号显示count: X

- ✅ **方法3（代码检查）**: 查看`insightSuggestions`数组

  - `.full_mode.code`是完整Python代码字符串
  - `.aggregated_mode.sql`是有效SQL字符串
