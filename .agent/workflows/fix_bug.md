# 🐞 Bug 修复工作流 (/fix_bug)

修复 Bug 时请遵循此流程，确保文档记录和根本原因分析（规则 #10）。

## 1. 分析 (Analysis - Pre-Fix)
1.  **复现**：在浏览器中确认 Bug 现象。
2.  **分析**：查看控制台日志 (Console Logs) / 网络请求 (Network Request)。
3.  **创建错误卡片**：
    *   打开 `docs/05-项目管理/51-管理-错误日志记录.md`。
    *   追加一条新记录，包含：
        *   **错误现象 (Symptom)**
        *   **发生位置 (Location)**
        *   **根本原因 (Root Cause)**
        *   **解决方案 (Solution)**
    *   *规则 #10：此步骤为强制要求。*

## 2. 执行修复 (Fix Implementation)
1.  **应用修复**：编辑代码。
2.  **检查副作用**：
    *   是否破坏了 Context/State 上下文？（规则 #12）
    *   文件是否超过了 500 行？（规则 #11）

## 3. 验证 (Verification)
1.  **全链路脚本验证**: 运行 `npm run verify`。
2.  **验证修复**：测试特定场景。
2.  **回归测试**：测试相关功能。
3.  **浏览器输出**：确认控制台无新报错。
