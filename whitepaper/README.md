## 🎯 快速开始指南

### **新用户推荐阅读顺序**：
1. 先阅读 [API Key 说明](./⚠️API-Key说明与限制.md) 了解基本策略
2. 如需本地部署，参考 [Ollama 教程](./📖零云依赖教程-Ollama部署.md)
3. 如关心隐私，深入阅读 [数据脱敏策略](./🔒数据脱敏策略说明.md)

### **生产环境部署清单**：
- [ ] 安装 Ollama 本地模型（推荐 Qwen2.5:7B）
- [ ] 或配置自己的 DeepSeek API Key（未来支持）
- [ ] 在 Settings 中启用"数据隐私 - 自动脱敏"
- [ ] 测试分析流程
