# 🔒 数据脱敏策略说明

本文档详细说明 LiuliX 的数据隐私保护机制与脱敏策略（基于实际代码实现）。

---

## 🎯 核心原则

LiuliX 遵循**最小化数据暴露**原则：

1. **本地优先**：推荐使用 Ollama 本地模型，数据完全不出本机
2. **用户可控**：云端模式下，用户可选择发送数据的粒度
3. **透明化**：明确告知用户哪些数据会上传云端

---

## 📊 三种数据处理模式

### 1️⃣ **本地模式（Ollama）**
**数据流向**：本地 → Ollama → 本地  
**隐私等级**：🟢 **完全隐私**

| 数据类型  | 是否上传 | 说明                       |
| --------- | -------- | -------------------------- |
| 原始数据  | ❌ 否     | 数据仅在浏览器 WASM 中处理 |
| 列名/表名 | ❌ 否     | 完全离线                   |
| 分析结果  | ❌ 否     | 所有推理在本地完成         |
| 元数据    | ❌ 否     | 无任何数据上传             |

**推荐场景**：所有涉及敏感数据的生产环境

---

### 2️⃣ **云端模式 - 自动脱敏（默认）**
**数据流向**：本地 → 脱敏 → 后端代理 → DeepSeek API  
**隐私等级**：🟢 **高度隐私**

**用户设置路径**：Settings → Performance & Quality → Data Privacy → **"自动脱敏"**（默认选中）

#### 🔒 上传的数据内容

**仅上传列元数据和统计信息，不含具体数据值**：

```json
{
  "columns": [
    {
      "name": "user_id",          // ✅ 保留原列名
      "type": "INTEGER",           // ✅ 数据类型
      "nullable": false,
      "isSensitive": true,         // 🔍 智能检测结果
      "stats": {
        "totalRows": 10000,
        "nullCount": 0,
        "uniqueCount": 9850,
        "min": "已脱敏",           // ❌ 敏感列隐藏最小值
        "max": "已脱敏",           // ❌ 敏感列隐藏最大值
        "patternExample": "敏感信息（已脱敏）"
      },
      "sampleValues": []            // ❌ 无样本数据
    },
    {
      "name": "age",
      "type": "INTEGER",
      "nullable": true,
      "isSensitive": false,        // 非敏感列
      "stats": {
        "totalRows": 10000,
        "nullCount": 50,
        "uniqueCount": 60,
        "min": 18,                  // ✅ 非敏感列保留统计值
        "max": 65,
        "mean": 35.2,
        "median": 34
      }
    }
  ]
}
```

#### 🔍 敏感列智能检测

系统会自动检测以下列名模式为敏感列：

**身份信息**：
- `id`, `user_id`, `customer_id`（含ID关键字）
- `name`, `username`, `姓名`
- `email`, `邮箱`

**联系方式**：
- `phone`, `mobile`, `电话`, `手机`
- `address`, `地址`

**财务信息**：
- `password`, `密码`
- `card`, `卡号`
- `account`, `账号`

**代码实现**（`src/utils/dataSanitizer.ts`）：
```typescript
function isSensitiveColumn(columnName: string): boolean {
    const lowerName = columnName.toLowerCase();
    const sensitivePatterns = [
        'id', 'name', 'email', 'phone', 'mobile',
        'password', 'card', 'address', 'account',
        '姓名', '电话', '手机', '邮箱', '地址', '密码'
    ];
    return sensitivePatterns.some(p => lowerName.includes(p));
}
```

#### **AI 仍可完成的任务**：
- ✅ 检测缺失值
- ✅ 识别异常值（基于统计范围）
- ✅ 发现列之间的相关性（通过类型和统计信息）
- ✅ 生成数据清洗代码

#### **AI 无法获取的信息**：
- ❌ 具体的数据值（如用户ID = 1001）
- ❌ 敏感列的分布细节（仅知道"有 10000 个 user_id"）

### 3️⃣ **云端模式 - 发送原始数据**
**数据流向**：本地 → 后端代理 → DeepSeek API  
**隐私等级**：🟡 **部分隐私风险**

**用户设置路径**：Settings → Performance & Quality → Data Privacy → **"发送原始数据"**

#### 上传的数据内容

发送**前 100 行采样数据**，包含真实值：

```json
{
  "sampleData": [
    { "user_id": 1001, "name": "张三", "age": 28, "income": 12000 },
    { "user_id": 1002, "name": "李四", "age": 35, "income": 25000 },
    // ... 最多 100 行
  ]
}
```

**适用场景**：仅供快速体验和测试，**不推荐用于生产环境**

## ⚙️ 如何配置数据隐私

### **步骤 1：打开设置**
Settings → Performance & Quality → **Data Privacy**

### **步骤 2：选择模式**

```
数据隐私
选择发送给云端AI的数据形式（本地模型无需配置）

( • ) 自动脱敏  [推荐]
       仅发送列名和统计信息，不含具体数据值
       
(   ) 发送原始数据
       发送采样数据到云端API以获得更准确的建议

💡 使用本地模型时，数据完全不会离开浏览器
```

### **默认设置**
- **新用户**：自动脱敏（`auto_sanitize`）
- **存储位置**：`localStorage` (`dataprism_privacy_config`)

## 🛡️ 技术实现

### **脱敏流程**

```
用户上传数据
    ↓
DuckDB 本地分析（获取列信息 + 统计）
    ↓
检查用户隐私设置
    ↓
├─ 本地模式 → 数据不离开浏览器
├─ 云端 + 自动脱敏 → 仅发送元数据
└─ 云端 + 原始数据 → 发送采样数据
    ↓
后端代理（仅转发，不存储）
    ↓
DeepSeek API
    ↓
结果回传（代码/建议）
    ↓
用户
```

### **核心代码**

**隐私配置管理**（`src/utils/dataPrivacy.ts`）：
```typescript
// 获取用户设置
export function getPrivacyConfig(): PrivacyConfig {
    // 默认：自动脱敏
    return { mode: 'auto_sanitize' };
}

// 保存用户设置
export function savePrivacyConfig(config: PrivacyConfig) {
    localStorage.setItem('dataprism_privacy_config', JSON.stringify(config));
}
```

**统一脱敏入口**（`src/utils/unifiedDataSanitizer.ts`）：
```typescript
export async function unifiedSanitize(
    columns: any[],
    stats: any[],
    sampleData: any[],
    options: UnifiedSanitizeOptions
): Promise<UnifiedSanitizeResult> {
    const userConfig = getPrivacyConfig();
    
    if (userConfig.mode === 'send_raw') {
        // 用户选择发送原始数据
        return buildRawMetadata(columns, stats, sampleData);
    }
    
    // 自动脱敏：智能检测敏感列 + 隐藏敏感统计
    const sensitiveColumns = columns.filter(c => 
        isSensitiveColumn(c.name)
    );
    
    return {
        metadata: columns.map(col => ({
            name: col.name,
            type: col.type,
            isSensitive: sensitiveColumns.includes(col),
            stats: {
                ...stats[col],
                min: isSensitive ? '已脱敏' : stats[col].min,
                max: is Sensitive ? '已脱敏' : stats[col].max
            },
            sampleValues: []  // 不发送样本
        })),
        privacyMode: 'sanitized'
    };
}
```

## ❓ 常见问题

### Q1: 自动脱敏会影响 AI 推理质量吗？
**A**: 影响很小（~5-10% 准确率下降）。AI 仍能通过**列名、数据类型、统计分布**推断数据特征，生成准确的清洗建议和代码。

### Q2: 为什么不改列名（如 `user_id` → `col_1`）？
**A**: 列名本身对 AI 理解数据结构很重要（如识别"时间戳列"、"ID列"）。我们仅隐藏**具体数值**，保留**列名和类型**，取得隐私与准确率的平衡。

### Q3: Ollama 云端模型（如 `deepseek-v3.1:671b-cloud`）是否会上传数据？
**A**: 是的。虽然通过 Ollama 调用，但云端模型需要将数据发送到 Ollama 的云端服务器。如果对数据隐私要求严格，请使用本地模型（如 `qwen2.5:7b`）。

### Q4: 平台会保存我的数据吗？
**A**: **绝对不会**。LiuliX 后端仅作为代理转发请求，所有数据处理在浏览器本地完成（DuckDB WASM + Pyodide），后端不存储任何数据。

### Q5: 如何验证数据安全性？
**A**: 
1. 打开浏览器 DevTools → Network 面板
2. 查看发送到 `/api/proxy` 的请求 payload
3. 自动脱敏模式下，payload 中不会有具体数据值
