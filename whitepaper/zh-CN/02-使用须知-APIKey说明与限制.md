# ⚠️ API Key 使用说明与限制

本文档旨在透明地说明 LiuliX 的 AI 服务策略及内置试用 Key 的使用限制。

---

## 🎯 核心策略

LiuliX 坚持 **"Local-First"** (本地优先) 策略。我们提供内置的云端 API Key 仅为了方便新用户 **快速体验** 产品流程，而非用于生产环境。

### 三种使用模式

| 模式        | **Local Mode** (推荐) | **Cloud Mode** (试用) | **BYO Key** (未来) |
| :---------- | :-------------------- | :-------------------- | :----------------- |
| **PRIVACY** | 🟢 **完全离线**        | 🟡 **数据上传**        | 🟡 **取决于供应商** |
| **COST**    | 🟢 **免费**            | 🟡 **消耗额度**        | 🟡 **自费**         |
| **LIMIT**   | 🟢 **无限制**          | 🔴 **严格限额**        | 🟢 **供应商限额**   |
| **SCENE**   | **生产环境**          | **仅供体验**          | **特定需求**       |

---

## 🔑 试用额度说明

为了防止滥用并控制成本，内置的 DeepSeek API Key 设有严格的使用上限：

### 1. 邀请码用户 (MVP阶段)
- **总计**：**20 次** (清洗 + 洞察)
- **权限**：解锁云端 DeepSeek 模型使用权限。

### 2. 非邀请码用户
- **权限**：仅限 **Local Mode** (本地模式)。
- **额度**：本地模型 (Ollama) **无限制**，但无法使用云端服务。

> 💡 **额度用尽后？**  
> 系统将暂停云端服务。请切换至 **[本地模式](./📖零云依赖教程-Ollama部署.md)** 继续使用，或等待未来版本支持配置自定义 Key。

---

## 🛡️ 防滥用机制

我们实施了多层防护措施：

1. **后端限流**：基于 `x-invite-code` 追踪调用次数。
2. **熔断机制**：当额度耗尽时，API 将返回 `429 Too Many Requests`。
3. **前端引导**：UI 会明确提示 "试用配额" 字样，引导用户转向本地模式。

**限制示例响应**：
```json
{
  "error": "邀请码额度已用完",
  "message": "您的邀请码额度已用完，请切换至本地模式继续使用。",
  "usage": 20,
  "limit": 20
}
```

## 🔧 常见问题 (FAQ)

### Q: 为什么给这么少的额度？
**A**: LiuliX 是一个本地优先的工具。云端 API 昂贵且存在隐私风险。我们希望用户不仅是"试用"云端，而是真正"拥抱"本地 AI，享受零成本、高隐私的分析体验。

### Q: 我可以购买更多额度吗？
**A**: 不可以。LiuliX 不销售 API 额度。如果您需要大量云端计算，建议等待 "Bring Your Own Key" (自定义 Key) 功能上线，直接使用您自己的 DeepSeek/OpenAI 账户。

### Q: 邀请码如何获取？
**A**: 目前仅在 Discord 社区小范围发放。
