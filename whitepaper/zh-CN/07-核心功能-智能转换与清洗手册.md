# 🛠️ 核心功能：智能转换与清洗手册

LiuliX 提供基于 Python 和 SQL 的双引擎数据处理能力，内置 35+ 种智能清洗技能。

---

## 🐍 Python 代码转换

LiuliX 集成了 **Pyodide** 环境，允许你在浏览器中直接运行 Python 代码清洗数据。

### 使用方法
1. 点击工具栏的 **"Code Transform"**。
2. 输入标准 Pandas 代码。变量 `df` 代表当前数据集。
3. 必须返回修改后的 `df`。

**示例：标准化列名**
```python
df.columns = [c.strip().lower() for c in df.columns]
return df
```

## 🧹 内置清洗技能 (Smart Cleaning)

系统根据列类型自动推荐清洗操作。以下是部分核心技能：

### 文本清洗 (Text)
- **Trim Spaces**: 去除首尾空格
- **To Lower/Upper**: 大小写转换
- **Remove Punctuation**: 去除标点符号
- **RegEx Replace**: 正则表达式替换

### 数值处理 (Numeric)
- **Fill Missing (Mean/Median)**: 均值/中位数填充
- **Z-Score Normalization**: 标准化处理
- **Outlier Removal**: 基于 IQR 的异常值剔除

### 日期时间 (DateTime)
- **Parse Date**: 智能日期格式解析
- **Extract Component**: 提取年/月/日/星期

## ⏪ 时间旅行 (Time Travel)

LiuliX 记录每一次数据变更的操作历史，形成一条可回溯的"时间轴"。

### 机制说明
- **不可变性 (Immutability)**：每一步操作都会生成一个新的数据视图 (View)，而不会修改原始文件。
- **快照 (Snapshot)**：系统维护操作栈，支持无限步数的 **撤销 (Undo)** 和 **重做 (Redo)**。
- **脚本导出**：所有的操作步骤最终可以导出为可执行的 Python 脚本。
